# 采购方法论

这里写的是买什么料都可能用到的做法，不绑某一种元器件。

现在有三篇。计划均衡和交期跟踪按工厂里常见的做法来写，标成判断。产业链洞察把电子料十个历史案例收成能再用的步骤。没有调查样本，也不引用某家公司的内部数据。

- [产业链洞察：从历史里抽出能再用的方法](/methods/industry-chain-insight)
- [采购计划均衡：削峰要有边界](/methods/leveling)
- [供应商交期跟踪](/methods/delivery-tracking)

电子料缺货时，预测稳不稳、交期记账清不清，会直接变成能不能拿到货的筹码。品类里的打法见 [实战打法](/categories/electronics/playbook)。

以后可以继续加：询价怎么比、安全库存怎么设上限、来料质量异常怎么闭环。没有把握写清楚的，先不要占一篇。
