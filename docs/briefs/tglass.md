# 英伟达把"芯片底座"扩到2.5倍，可底座里那块"布"跟得上吗？

**T-Glass低膨胀玻璃布：日东纺、南亚、旭化成、台玻、宏和、泰山、建滔，谁在补这块布**

*开源情报研究笔记｜2026年10月26日（北京时间）｜只整理公开信息，不构成投资建议*

---

## 先说结论（TL;DR）

1. **英伟达的"2.5倍"和日东纺的"翻倍"不能直接比。** 2.5倍说的是：从现在算起3年里，基板厂给英伟达留的底座产能[1]。翻倍说的是：到2028年3月，日东纺T玻璃产能是2024年4月的2倍[3]。两个数的起点不一样，范围也不一样。把两个数都换成"从今年往后还能涨多少"，日东纺大约还能再涨1.2到1.6倍。这个区间是我按假设算的，见第四节。英伟达那边是每年平均涨三成多。
2. **最紧的一步是"织布"，不是"做玻璃"。** 日东纺自己承认，织布这一步跟不上。所以它把一部分织布交给台湾南亚。到2027年，它卖出的玻璃布里约两成由南亚织[9][4]。
3. **竞争已经开始，而且是日东纺自己说的。** 2026年8月，日东纺说客户在评估别家的低膨胀玻璃[5]。台玻说它的同类产品已通过认证并开始交货[20]。宏和说它的低膨胀布2025年已批量进入封装基板供应链[17]。
4. **"日东纺占全球九成"这个数来自日经报道，不是公司披露。** 公司材料只说"压倒性的头号份额"，没有给数字[13][12]。"旭化成进入T-Glass"也一样：目前只有日经报道。旭化成自己的投资者材料讲的是低介电布和石英布，没有提低膨胀布[14]。

我的非共识判断是：**这块布的"缺"，大概率不会变成"断供"，而会变成"分级"。** 意思是：最难、最大的AI芯片底座继续用日东纺的布；要求低一点的层和产品，会逐步换成第二家供应商的布。所以接下来更值得盯的，可能不是日东纺还涨不涨价，而是二供的认证消息。这是推断，第八节写了"如果我错了会怎样"。

## 一、先把东西讲清楚：底座、夹心、钢筋

**芯片底座（封装基板）。** 打个比方，它像一块"转接插线板"。AI芯片上有几万个比针尖还小的触点，主板接不了这么细的东西。底座把这些细触点一层层"转"成主板能接的大触点。英伟达新闻稿里的"substrate"就是它[1]。

**ABF和BT。** 它们是底座的两种主要材料，你可以把底座想成一块夹心饼干。中间那片硬"饼干"叫芯板。上下两面一层层很薄的"奶油"是走线层，ABF就是做奶油层用的一种绝缘膜。BT是另一种常用在芯板里的树脂。

**玻璃布。** 芯板这片"饼干"里，要埋一张用玻璃丝织的布。它的作用像钢筋混凝土里的钢筋网，让芯板又硬又不变形。

**玻纤纱和织布机。** 把玻璃烧化，拉成比头发细几十倍的丝，就是"纱"，像把棉花纺成棉线。再用织布机把纱织成布，像织毛巾，只是线细到一碰就断。织完还要"处理"：给布表面涂一层能和树脂粘牢的东西，像刷墙前先刷底漆。日东纺把整个过程分成三步：做纱、织布、处理[9]。

**CTE，也就是热膨胀。** 东西一热就会变长一点，所以夏天铁轨之间要留缝。芯片是硅做的，受热几乎不长个。底座里的树脂受热长得多。两样东西粘在一起加热，就会像一片两层不同金属的铁片，一热就弯。这叫"翘曲"。底座越大，弯得越厉害。

**T-Glass。** 这是日东纺做的一种特殊玻璃，"热了几乎不长个"，而且更硬[12]。把它织成布放进芯板，等于给底座换上一套不怕热的钢筋，翘曲就能压住。日东纺在公告里说，2024年起AI芯片开始把好几颗芯片拼在一块大底座上。底座一变大，翘曲问题就冒出来了，于是T玻璃布被大量采用[8]。

另外两个词会顺带出现。**低介电（Low-Dk）布**让信号跑得快、不走样，像把跑道铺平。它主要用在服务器主板，不是本文主角。**HVLP铜箔**是表面特别光滑的铜箔，像把高速路面磨亮，信号损失更小。建滔说这类铜箔也供不应求[19]。

## 二、英伟达10月21日到底说了什么

英伟达宣布和6家供应链伙伴扩产。和底座有关的是3家：揖斐电（IBIDEN）、三星电机、欣兴（Unimicron）[1]。原文是：英伟达计划在未来三年，把"给它自己产品用的"底座产能提高到2.5倍，"还有更多在推进"[1]。

几个细节：

- **揖斐电：** 英伟达给大野工厂付了"数十亿美元级"的产能预留预付款。目标是这座工厂产能到现在的3倍，2028年第一季度开始爬坡[1]。英伟达原文也说，这份协议揖斐电"今年早些时候已签署并公布"[1]。揖斐电2026年2月26日的公告是：2026到2028财年合计投资约5000亿日元，其中大野工厂约2800亿日元，2027财年起量产[2]。所以这一笔是"早已在建、现在锁定"，不是凭空新加的。
- **三星电机：** 韩国现有产能马上可用，再加世宗、釜山的新厂。原文说，到2028年，它的封装基板产能会有"相当大一部分"分给英伟达[1]。
- **欣兴：** 扩产从2027年第二季度开始贡献，2028年年中满产[1]。
- **名单里没有任何玻璃布公司，也没有中国大陆公司**[1]。

打个比方：这像餐厅答应给英伟达多留2.5倍的座位。座位可以靠"加盖新楼"多出来，也可以靠"把别的客人的位子让出来"。三星电机那句"相当大一部分分给英伟达"，说明里面至少有一部分是"让位子"。所以，英伟达的2.5倍不等于整个底座市场的2.5倍，更不等于玻璃布需求的2.5倍。

## 三、日东纺自己说了什么（原始材料）

我读了日东纺最近三次业绩说明会的问答纪要，还有中期计划修订和两份公告。

- **产能节奏（2025年11月6日）：** 和2025财年比，2026财年T玻璃产能多10%到20%。2027财年是中期计划开始时（2024财年初）的2倍[3]。注意：公司说的是"能力"，没拆开说是纱还是布。
- **销量（2026年2月5日）：** 2026财年T玻璃销量预计比上一年多20%左右。2027财年完成的扩产会让销售"真正放量"。更多扩产"正在作为重要经营课题研究"[4]。
- **2028年（2026年8月5日）：** 公司在按计划执行到2028年的扩产。"只要需求持续，就优先把资源投给T玻璃"；"机会大，就毫不犹豫地投资"[5]。
- **钱：** 中期计划（2024到2027财年）4年设备投资，从约800亿日元上调到约1200亿日元。2027财年营业利润目标从200亿上调到360亿日元[6]。电子材料部门2026财年营业利润预计280亿日元，上一财年是194亿日元[7]。
- **福岛新厂（2025年8月29日公告）：** 投资约150亿日元，2027年1到3月开始生产。增加的主要是"处理"设备。公告说，如果新增能力全部用来做最先端AI芯片用的T玻璃布，大约是现在产量的3倍[8][9]。这是"全部用上"的上限，不是承诺。
- **南亚代织（2025年11月28日公告）：** 日东纺把"织布"的一部分交给台湾南亚塑胶。到2027年，日东纺集团卖出的全部玻璃布里约20%由南亚织[9]。南亚当天的新闻稿口径一样[10]。2026年1月，南亚说已经正式投产，"不排除再加量"[11]。

这里要分清一个口径：20%是"日东纺全部玻璃布"的两成，不是"T玻璃布"的两成[9]。

**为什么要外包织布？** 日东纺在2026年2月说得很直白：纱自己能多做，福岛新厂补的是"处理"，可"织布"这步追不上，所以要借南亚的织布机[4]。统合报告里还说，这是从"什么都自己做"转向"轻资产"，把力气集中在最难的熔玻璃、拉细纱和表面处理上[12]。

**织布机为什么紧？** 高盛和建滔管理层交流后的纪要说：织布机供应仍紧张，建滔今年的织布机已经锁定，2027年还要再买；国产织布机在增加，但近期仍以海外产品为主[22]。这是券商纪要经媒体转述的，我没看到原文。

## 四、不重复计算：两个数怎么才能放在一起看

先把两个数的"尺子"写清楚：

| | 英伟达 2.5倍 | 日东纺 2倍 |
|---|---|---|
| 量的是什么 | 三家基板厂分给英伟达的底座产能 | 日东纺T玻璃产能（全部客户） |
| 起点 | 现在（2026年10月） | 2024年4月 |
| 终点 | 约3年后（约2029年） | 2028年3月（2027财年末） |
| 来源 | [1] | [3] |

两个数的起点不同，所以不能直接写"2.5大于2，所以缺布"。日东纺的翻倍里，有一部分在2024到2026年已经发生了，并且已经被现在的英伟达产品用掉了。

**换成同一个起点。** 我想知道的是：从今年开始，日东纺还能再涨多少？公司没有公布2025财年产能比起点高多少，所以只能做假设：

- 假设A（前面涨得少）：2025财年是起点的1.1倍。那么2026财年约1.27倍，到2027财年的2倍还要再涨约1.6倍。
- 假设B（中间）：2025财年是起点的1.3倍。那么2026财年约1.5倍，还要再涨约1.3倍。
- 假设C（前面涨得多）：2025财年是起点的1.5倍。那么2026财年约1.73倍，还要再涨约1.16倍。

计算方法：2026财年按比2025财年多15%算，这是公司给的10%到20%的中点[3]。三个假设都是我的，不是公司数据。

**再比速度。** 英伟达3年2.5倍，大约是每年多36%。日东纺从2026财年到2027财年这一步，按上面三个假设，是多16%到58%。2028财年以后的扩产，公司没给数字。

**为什么这样比还是不够。** 有三件事会让结果往两个方向偏，我没法把它们抵消：

1. **往"更紧"偏：** 每块底座用的布可能更多。台湾法人说，新一代底座层数更多、尺寸更大，用的面积大幅增长[11]。另外，手机、内存的底座也开始用薄T玻璃，在跟AI抢货[3][7]。
2. **往"更松"偏：** 英伟达的2.5倍里有"让位子"的成分（见第二节），整个市场的底座需求涨不到2.5倍。
3. **我们不知道英伟达占日东纺T玻璃多少。** 如果只占一小部分，日东纺可以从别的客户那里挪量。

所以我的结论只能是区间式的：在中间假设下，日东纺单独一家的增速和英伟达底座增速大致同一个量级；只要"每块底座用布变多"成立，光靠日东纺就不够快，需要南亚代织和第二家供应商补。时间上最紧的是2027年：三星电机的现有产能马上给英伟达，欣兴从2027年二季度开始加，而福岛新厂和南亚代织都还在爬坡。

## 五、第二家供应商：谁说了什么，说到了哪一步

"认证"是什么？换一种布，就像药厂换一种原料，客户要从头做一轮测试，看会不会翘、会不会脱层、良率掉不掉。通常要几个月到一年以上。所以"送样""通过认证""批量供货""进入英伟达"是四个不同的台阶。

- **台玻（台湾）：** 2026年1月，台玻说"市场俗称T-Glass的低膨胀产品已通过认证开始交货"，订单能见度到2027年上半年[20]。没说客户是谁。
- **富乔（台湾）：** 2026年9月报道，低膨胀纱已取得日本和海外客户认证，低膨胀布还在认证中[21]。
- **宏和科技（603256）：** 年报说，低膨胀电子布2025年已批量生产，"顺利进入封装基板终端供应链"[17]。它在回复上交所问询时列出：低膨胀布主要客户有力森诺科、台光、生益、斗山、三菱瓦斯、盈骅；松下、联茂、华正、LG化学、南亚新材在送样认证[16]。力森诺科和三菱瓦斯都做底座芯板材料。产能方面，宏和的高性能纱（低介电和低膨胀合计，不单拆）现有约200吨，募投新增1254吨，预计2028年上半年完全释放[16]。
- **泰山玻纤（中材科技002080旗下）：** 2026年半年报说，特种布（低介电一代、二代、低膨胀、超低损耗合计）上半年卖了1345万米，同比多50%；"第三代低膨胀产品突破薄型化，样品进入多家头部客户测评"[18]。低膨胀布单独的产能和销量没有披露。
- **建滔积层板（1888.HK）：** 2026年中期业绩公告说，清远在建8座特种纱窑炉，2座下半年投产。全部投产后，特种纱窑炉增至13座，产品包括低介电一代、二代、低膨胀和石英纱[19]。没有披露低膨胀产品的认证或客户。
- **旭化成（日本）：** 日经2026年4月报道它要进入"热膨胀强的绝缘材"，追赶"占全球九成份额"的日东纺[13]。旭化成2026年1月的说明会讲的是低介电布、石英布，以及"原纱可以从多家供应商选"[14]。也就是说，它主要是织布厂，玻璃纱是买来的。它的低膨胀纱从哪来，我没找到。

**对"中国视角"要诚实：** 宏和、泰山、建滔都有低膨胀产品，宏和的已进入封装基板供应链。但它们的布有没有进到揖斐电、三星电机、欣兴给英伟达做的底座里，**未确认**。网上有帖子说泰山"进入英伟达供应链"。那是论坛帖子，不是公司披露，而且帖子自己也写了"载板级极薄T布还在验证"[24]。

## 六、价格：日东纺在"保量"还是"加价"？

- 2025年11月：公司说因为还要持续投资，正在和客户谈从2026年开始的涨价，幅度和时间因客户而异[3]。
- 2026年2月：如果需要更多扩产，会请客户理解"追加涨价"[4]。
- 2026年5月：据第三方Postation引用的问答纪要，公司说T玻璃"没有进一步涨价的计划"，要靠满足客户扩量需求来维持高份额[15]。这份5月纪要原文我没读到。
- 2026年8月：涨价不和投资决定挂钩，等扩产让供应量真正多出来的时候再考虑。眼下要先把供应能力提上去，"维持市场份额"[5]。

这几句话放在一起看，口气在变：从"要涨"变成了"先保量、守份额"。最直接的原因，公司自己说了：客户在评估别家的低膨胀玻璃[5]。

对比一下普通电子布：中国证券报10月19日报道，7628这种厚布从2025年9月的每米约3.9元涨到13.5到14元[23]。另据中证报，建滔10月13日把用2116及更薄布做的板料和半固化片涨价15%[23]。这些都不是T玻璃，但能看出整个"布"的链条都紧。

## 七、我的判断：缺口会变成"分级"

我的推理链是这样的：

1. 因为英伟达这次把钱预付给了基板厂，名单里没有玻璃布厂[1]。所以英伟达眼里最紧、最需要自己出钱锁的是底座产能，布由基板厂和材料厂自己去找。这是推断。
2. 因为日东纺短期内补不上织布[4]，客户又等不起，所以客户开始认证别家[5]。
3. 因为认证是一层一层走的，二供的布会先用在要求低一点的地方：比如薄布、手机和内存底座、层数少的芯板。最大最难的AI底座先不换。这是推断，没有直接证据。
4. 所以日东纺大概率还是"最难那一块"的主力，但它的定价权会从"加价"慢慢变成"保量"。它在8月的表态已经有这个味道[5]。

## 八、如果我错了，会是什么情况

- **日东纺扩得比我想的快：** 如果11月5日的业绩会上，公司公布2028年以后的具体产能数字，或者南亚代织比例明显高于两成，2027年就未必紧。二供会被挤压。
- **客户换料比我想的快：** 如果台玻、宏和、泰山在大尺寸AI底座上也通过认证，"分级"会变成"真正的份额下滑"，日东纺守不住"头号"。
- **底座规格被改：** 如果厂商用更厚的芯板、换别的增强材料，或者转向玻璃芯基板（用一整块玻璃代替"布+树脂"做芯板），每块底座的T玻璃用量会下降。玻璃芯基板目前还在早期，量产时间我没核实。
- **英伟达的2.5倍大多是"让位子"：** 那整个市场的布需求就涨得不多，"缺"会比想象中早结束。
- **需求本身降速：** AI服务器订单放缓，所有扩产会在2028年前后同时投产，变成过剩。这和光纤那篇的逻辑一样。

## 十、这跟普通读者有什么关系

一块AI芯片能不能按时出货，不只看台积电，也看底座里一块比纸还薄的布。英伟达这次直接给基板厂付钱锁产能，说明这条链上真正"跑不快"的是这些不起眼的材料和工序。看懂"纱、布、织布机、认证"这几步，就能看懂下一个"缺货"会出在哪里。
