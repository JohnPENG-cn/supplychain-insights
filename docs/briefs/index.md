# 产业链情报中心

实事分析。

<p class="brief-meta">更新 2026-10-27</p>

这里的「情报」，是海关、公告、许可、产能、交期这些能打开核对的公开信号，不是内部消息，也不是小道消息。

这一栏不教你怎么买某一类料，也不放会自动刷新的曲线。它做一件事：用这些信号，找出这一轮真正卡住出货的那一层。说人话。每篇都标明哪些是事实、哪些是推断、哪些还没核实。不构成投资建议。

## 这一栏怎么写

<!--@include: @/snippets/brief-note.md-->

和另外两栏分开：

- [产业链洞察](/methods/industry-chain-insight) 从已经发生过的电子料案例里抽步骤。
- [产业链看板](/dashboard/) 放能反复核对的曲线。现在只有 MLCC。
- 这一栏按篇发布。标题下面写着发布日期和更新日期。过了那个日期，就当历史，不要当成今天的行情。

每篇标题下面有一段口语音频。音频不念来源和脚注，表格改成口述。数字和出处以正文和文末链接为准，不要只听音频。

## 和品类页怎么一起看

电子料怎么买，仍从 [电子元器件与芯片](/categories/electronics/) 进入。这一栏里和现有页面挨得近的，是磷化铟的出口许可（可对照 [安世案例](/categories/electronics/cases/nexperia)，物项不同），以及封装基板里的低膨胀玻璃布（可对照 [PCB 和覆铜板](/categories/electronics/parts/pcb-ccl) 和 [HBM 案例](/categories/electronics/cases/hbm-ddr)）。光纤目前没有对应的品类页。
