## 核心论点（TL;DR）

市场流行的说法是："磷化铟被中国卡住了，美国光芯片要断供。"这句话方向对，但颗粒度太粗。按供应链的方式拆开看（产能保留、预付、配给、认证周期、交期、BOM占比），能得到四个更具体的判断：

1. **原料在跌，成品在涨，卡点不在矿。** 10月国内精铟从5250元/公斤（10/14）跌到4750元/公斤（10/21）；同期4英寸磷化铟衬底均价从7050元涨到7100元/片，并且普遍要求预付50%以上。按密度估算，一片4英寸衬底含铟约19克，金属成本只占衬底售价的约1%–5%。真正稀缺的是长晶良率、加工能力，以及每一单出口都要拿的商务部许可。[17][18][19][1]
2. **成本占比极小，议价权极大。** 自下而上估算，一只1.6T EML模块摊到的衬底成本约2美元，不到模块售价的1%（中性情景约0.25%）。把面积、良率、衬底价格三个假设推到两头，区间是约0.6–22美元，占模块售价约0.1%–3%。这是采购教科书里的"瓶颈物料"，所以买方用押金、预付和照付不议（take-or-pay）锁量，而不是谈价。AXT的非GAAP毛利率一年内从8.2%升到45.0%。[2][3]
3. **北京卡的是"增量"和"配给"，不是"存量"。** Lumentum CEO说，它的主力衬底来自一家日本供应商；AXT 2025年北美营收只占约2%（2024年约8%）。[8] 北京真正握着的，一是全球扩产最快的那部分产能：AXT计划季度营收产能从2026年底的约6000万美元，提到2027年底的约1.3亿美元；二是"内销优先"：内销不需要许可，已经占AXT营收的一半以上。许可证在这里的作用更像配给工具，而不是禁运。[2][4][7]
4. **镜像卡脖子：中国握衬底，美日握200G EML芯片。** 中际旭创说高端光芯片"供应商偏少、生产周期更长"；源杰科技的200G EML截至10/14仍在客户验证。硅光方案每只模块只用几颗CW激光器，单模块的磷化铟用量大约只有EML方案的三分之一，所以它同时是国内模块厂绕开EML的出路。[20][21][22]

## 一、为什么是磷化铟：物理决定了没有便宜的替代品

数据中心单模光链路工作在1310nm（O波段）附近。能在这个波段高效发光、同时能被高速调制的激光器，有源层基本都是长在磷化铟（InP）衬底上的InGaAsP/InGaAlAs量子阱。砷化镓（GaAs）衬底上的VCSEL便宜、能做阵列，但主要服务850nm多模短距链路。AXT CEO在2026年7月的业绩会上说得很直接：VCSEL很难做到每通道200G，200G需要磷化铟激光器和探测器。[2]

| 方案 | 衬底 | 典型用途 | 每只1.6T模块的InP器件（估算） | 主要供应商 |
|---|---|---|---|---|
| EML（DFB＋电吸收调制器单片集成） | InP | 1.6T DR8/FR8，中长距 | 8颗EML＋8颗InP探测器 | Lumentum、Coherent、三菱电机、住友电工、Broadcom；国内：光迅、索尔思（东山精密）等[假设，见第六节] |
| 硅光（外置CW光源＋硅调制器） | 光源用InP，调制器用硅 | 1.6T DR8，CPO/NPO | 2–4颗CW激光器（探测器多为硅上锗）[假设] | CW：Lumentum、Coherent、源杰、三安等 |
| VCSEL | GaAs | 多模短距（≤100m） | 0 | Coherent、Broadcom等 |

需要注意的是，硅光并不能消灭对磷化铟的需求，它只是把用量从"8颗调制激光器"压缩成"几颗大功率连续光源"。CPO用的300–400mW超高功率CW激光器，单颗芯片面积明显更大。[24] Lumentum说，超高功率激光器的供应"更加落后于需求"。[4]

## 二、自下而上：一只1.6T模块到底吃掉多少磷化铟

公开资料里没有厂商级的单片出芯数据，所以下面全部是**带假设的估算**。目的是确定数量级，而不是给出精确值。

**假设表**

| 参数 | 取值 | 依据 |
|---|---|---|
| 晶圆 | 4英寸（100mm），边缘去除3mm，排布效率85% | 工程常规假设 |
| 可用面积 | 约5,900 mm² | 计算值：π×47²×0.85 |
| 单颗EML面积（含划片道） | 0.2 / 0.3 / 0.465 mm² | 0.465 mm²取自OFC 2022论文里一颗100GBd EML阵列单元（750×620µm）[25]，0.2和0.3为假设 |
| 综合良率（外延＋流片＋测试＋可靠性筛选） | 10% / 30% / 50% | 假设。二手资料称高端EML可靠性筛选严格，"单片有效产出可低至几百颗"（这一说法可能指2英寸片）[24] |
| 每只1.6T EML模块 | 8颗EML＋8颗探测器 ≈ 11颗EML当量面积 | 假设：探测器面积约为EML的一半 |
| 每只1.6T硅光模块 | 约4颗CW当量 | 假设 |
| 4英寸衬底价格 | 800 / 1,000 / 2,500美元 | 800美元以上为通美海外报价（腾讯新闻号"一财有看投"转引，10/17）[19]；1,000美元约等于国内均价7,100元（按1美元≈7.1元假设）；2,500美元为压力测试 |

**结果**

| 情景 | 每片4英寸良品芯片 | 1.6T EML模块的衬底成本 | 1.6T硅光模块的衬底成本 |
|---|---|---|---|
| 悲观（0.465mm²、10%良率、2,500美元/片） | 约1,270颗 | 约21.7美元 | 约7.9美元 |
| 中性（0.3mm²、30%良率、1,000美元/片） | 约5,900颗 | 约1.9美元 | 约0.7美元 |
| 乐观（0.2mm²、50%良率、800美元/片） | 约14,750颗 | 约0.6美元 | 约0.2美元 |

二手报道称1.6T模块ASP约700–800美元。[27] 据此，中性情景下衬底约2美元，不到模块售价的1%（约0.25%）；悲观情景约22美元、约3%；乐观情景约0.6美元、不到0.1%。另一份付费研究给出的数字是"约2%"[24]，腾讯新闻号"一财有看投"称"占光模块BOM极低个位数"[19]。这两个说法都落在我的区间里，但更靠近悲观一端，比中性情景高。

**再往上游走一层：铟金属占衬底多少？** InP密度4.81 g/cm³，铟的质量分数约78.8%。一片厚625µm的4英寸片约24.4克，含铟约19.2克。按10/21的精铟价4,750元/公斤[18]，这只值约91元。如果材料全部用上，铟金属只占7,100元衬底售价的约1.3%；即使长晶、切磨抛的综合材料利用率只有25%–50%（假设），也只占约2.6%–5.1%。TL;DR里的"约1%–5%"就是这两种算法的合并区间。

**结论：** 磷化铟衬底是一个金额很小、却决定整只模块能不能出货的物料。对买方来说，晚到一周的代价是整条模块线停产，所以价格几乎没有弹性。这解释了第五节里那些押金和照付不议条款。

**交叉验证（附带一个牛鞭效应的疑问）：** 假设2026年出货2,000万只1.6T模块（第三方预测在1,000万到3,300万只之间[27]，未核实），EML和硅光各半。中性情景下需要约2.5万片4英寸衬底，约合10万片2英寸当量；悲观情景下约47万片2英寸当量。中邮证券转引的Omdia/Yole口径是：2026年总需求260万–300万片2英寸当量，有效产能约75万片，缺口近70%。[23] 就算加上800G、电信、传感和PON的需求，"需求"数字仍比1.6T的自下而上用量高出一个数量级。可能的解释有三个：良率比悲观情景还差；渠道里有重复下单和安全库存，也就是牛鞭效应；口径不同。这个差距本身就是一个值得追踪的风险点（见第九节空方观点）。

## 三、供应结构：谁在长晶

### 3.1 全球格局

| 环节 | 主要玩家 | 份额与产能（时间点） | 卡点类型 |
|---|---|---|---|
| 精铟 | 中国约占全球精炼产量70%；美国2021–2025年精炼产量为零，100%进口 | USGS MCS 2026（经二手转引）[7][16] | **非卡点**：金属铟本身不在第10号公告的管制清单内，价格在跌 |
| 有机铟前驱物（TMIn/TEIn） | 多家 | 已列入管制3C004.b/c[1] | 外延用料，许可管理 |
| InP单晶与衬底 | 住友电工、AXT/北京通美、JX金属；Freiberger（德国）；国内：云南锗业（鑫耀）、先锐（光智科技控股）、鼎泰芯源等 | Yole 2020：住友42%、AXT 36%、JX 13%[15]；路透2026年称住友加AXT"主导全球生产"[31]；国内非AXT厂商约占全球供应10%[16] | **长晶良率＋认证＋许可** |
| 外延 | IQE、Landmark、IntelliEPI，以及激光器厂内部 | IQE CEO称获取InP衬底是供应风险，2026年下半年把机台转向InP[6] | 二手资料称MOCVD交期10–12个月[24]（未核实） |
| 激光器/探测器晶圆厂 | Lumentum（日本2座、圣何塞、Greensboro）、Coherent（Sherman 6英寸、Järfälla、苏黎世）、三菱电机、住友电工、Broadcom | 三菱电机自称数据中心EML芯片全球份额第一（FY25，公司自估）[14] | **200G EML/大功率CW产能与认证** |
| 光模块 | 中际旭创、新易盛、Coherent、Lumentum等 | 中国厂商份额领先 | 光芯片和DSP供给 |

有两个细节值得注意。第一，关于EML份额，一个二手研究源称Lumentum加Coherent占商用EML的80%以上（cohr.primarysourced.com，二手估算），而三菱电机在自己的投资者材料里称数据中心EML全球份额第一（公司自估）。[14] 两种口径打架，说明EML市场份额没有公认数字。第二，住友在2026年7月把InP衬底扩产投资提高到约180亿日元，目标是FY2028产能达到FY2024的3.1倍。[13]

### 3.2 从4英寸到6英寸：增量往哪边倾斜

Coherent在2024年3月宣布，在德州Sherman和瑞典Järfälla建成全球首个6英寸InP晶圆制造能力，单片器件数约为3英寸的4倍，单颗芯片成本降低60%以上。[9] Sherman的6英寸线在2025年9月季度投产，公司称初期良率高于3英寸线。2026年6月16日，商务部CHIPS项目对Sherman扩建发出最高5,000万美元的意向书，计划把面积从7万平方英尺翻倍到14万，晶圆产能提高到4倍。[10]

但晶圆厂是6英寸，不等于衬底也在美国。Coherent在2026年6月与AXT北京子公司通美签了一份初始期3年的**6英寸**InP衬底协议，预付22,288,500美元（约2,229万美元）。[6][7] AXT管理层说，6英寸长晶"难度呈指数级上升"，但在推进。[2] 换句话说：**美国唯一量产的6英寸InP晶圆厂，有一部分6英寸衬底合同签在北京。** 协议没有披露交货地；在对美许可放行之前，这部分衬底能否送进Sherman，取决于商务部。[7]

## 四、许可证如何运作：从"禁运"到"配给"

**制度。** 商务部和海关总署2025年第10号公告于2025年2月4日起实施，对以下物项实施出口许可管理：磷化铟（3C004.a，HS 2853904051）、三甲基铟和三乙基铟（3C004.b/c，HS 2931900032），以及相关生产技术（3E004）。公告没有对美专条，也没有到期日；**金属铟本身不在清单内**。[1]

**时间线**

| 时间（北京时间） | 事件 | 来源 |
|---|---|---|
| 2025-02-04 | 第10号公告生效 | [1] |
| 2025-03 | 申请通道开放 | [6] |
| 2025-06-11 | AXT拿到首批许可（欧洲、日本客户） | [6] |
| 2026-01-08 | AXT因许可发放少于预期，下调2025年四季度展望 | [6] |
| 2026-05 | 白宫事实清单称中方"将处理"包括铟在内的短缺关切；中方成果文件没有提到铟 | [7] |
| 2026-07-31 04:30 | AXT二季报：三季度指引6,600万美元，只计入已获许可或不需许可的订单 | [2] |
| 2026-08-13 | AXT 10-Q：对美磷化铟许可仍"无法预估"何时获批，称许可是"最重大的挑战" | [6][7] |
| 2026-09-23 | 美方称休战延长到2027-01-10；截至10月中旬，商务部第70号公告的法定到期日仍是11-10，尚无新的编号公告 | [29]（二手） |

**机制上的要点（这是供应链视角最关键的一点）：**

- **没有订单就不能申请许可。** 所以积压订单本身就在"排队拿许可"。AXT说积压订单超过1亿美元、覆盖两个季度以上，并且不含大部分中国业务；它已经"不再接超出计划产能的订单"。[2]
- **内销不需要许可。** AXT二季度中国境内收入占比超过50%，长期模型为40%–60%；中国InP激光器客户的收入环比翻倍以上。[2]
- **许可节奏有地域差异。** 管理层说某些地区的许可"更有规律、更快"；对美国客户的许可截至8月仍是零。[2][6]

把这三条合起来看，许可证的实际效果是一个**优先级排序器**：国内激光器厂不用排队，日欧客户排队但能拿到，美国客户排在最后。在一个整体售罄的市场里，排序本身就是定价权。

## 六、镜像卡脖子：中国模块厂的命门在200G EML

如果只讲"中国卡美国"，这篇就成了宣传稿。反方向的依赖同样真实。

- **中际旭创**（2026-01-31投关记录）：高端光芯片"供应商偏少，且生产周期更长"；EML和CW"相对更加紧缺"；公司已经和供应商商定今明两年的整体供给、锁定产能；并且要靠提升硅光占比来扩大CW光源的供给。1.6T里硅光的占比高于800G。[22]
- **源杰科技**（2026年半年报和10/14投关记录）：上半年营收9.25亿元，同比增长351%，其中数据中心业务占83.77%。CW 70/100mW和100G PAM4 EML已经批量出货；**200G PAM4 EML仍在客户验证**；产能向CW倾斜。[20][21]
- **其他国产厂商**（以下多为自媒体或二手信息，**未核实**）：索尔思（东山精密）宣称200G EML规模量产；光迅科技小批量量产；长光华芯在大会上披露计划三季度量产；仕佳光子的目标是三季度小批量。

| 层级 | 谁握着 | 对方的替代时间 |
|---|---|---|
| InP衬底的增量产能 | 北京（AXT/通美）＋国内厂商 | JX扩产7–10倍需要4年；住友到FY2028扩到3.1倍；三菱电机EML产能到FY2030扩到3倍以上[12][13][14] |
| 200G EML芯片 | Lumentum、Coherent、三菱、住友、Broadcom | 国内200G EML还在验证或小批量阶段，硅光CW是绕行路线 |

**这里的非共识之处在于：** 两边的筹码不在同一层，也不在同一个时间点。中国的衬底筹码会随着JX和住友扩产而贬值，时间是2027–2029年。美日的EML筹码会随着国内硅光和200G EML的验证通过而贬值，时间可能更早。所以谁的筹码先贬值，比谁今天握着筹码更重要。

## 七、杠杆地图：先断哪一环

| 环节 | 稀缺程度 | 替代周期 | 判断 |
|---|---|---|---|
| 金属铟 | 低（价格下跌，不在管制清单） | — | 不是卡点 |
| 2–4英寸衬底（日本以外的增量） | 高 | 新长晶线需要18–20个月，外加客户认证（二手资料[24]） | 许可是开关 |
| 6英寸衬底 | 极高（二手资料称6英寸长晶良率低于15%[24]，未核实） | 数年 | **最可能先断**：6英寸晶圆厂扩产越快，越依赖少数会长6英寸晶体的厂商 |
| MOCVD外延 | 高 | 设备交期10–12个月（二手资料，未核实） | 次级卡点 |
| 200G EML与大功率CW芯片 | 极高 | 新晶圆厂约需2年（Greensboro到2028年初才有营收[4]） | **当前实际卡住出货的环节** |
| 模块组装 | 中 | 数月 | 不是卡点 |

**排序：** 今天卡住出货的是激光器芯片，不是衬底（Lumentum自己说EML"到2026年底仍显著落后需求"[4]）。等到2027–2028年6英寸晶圆厂集中爬坡，Sherman扩到4倍、Greensboro在2028年投产，**6英寸衬底和对美许可**会从后台走到前台。

## 九、多空与什么会改变看法

**支持"北京握有关键杠杆"的证据（多方）**
- AXT三季报的指引口径仍是"已获许可"，并且对美许可继续为零。
- Lumentum或Coherent在财报中表示需要更多衬底来源，或把衬底来源列为风险。[4]
- 6英寸衬底的合格供应商仍然集中，Sherman和Greensboro的爬坡受制于衬底。
- 11/10暂停措施到期前后，商务部没有发布对美的通用许可。

**削弱这个判断的证据（空方）**
- 商务部对美国客户批出磷化铟许可，或发放通用许可。
- JX或住友的扩产提前落地；Lumentum继续"相当放心"。
- 硅光和VCSEL渗透超出预期，单模块InP用量下降。
- 牛鞭效应反转：重复下单被识别出来，衬底现货价下跌、预付比例下降。第二节里"需求"与自下而上测算之间一个数量级的差距，是这条空方逻辑的伏笔。
- 中国内需吸收AXT的全部增量，对美出口许可变得无关紧要，杠杆也就不再存在。

**会让我改变看法的单一信号：** AXT的10-Q里出现"已获得对美磷化铟出口许可"。
