# 品类采购经验

按你实际在买的东西分。每一类只写这类料特有的坑：谁掌握价格、交期看什么、替代要动到哪一层。

跨品类都用得上的计划方法和交期记账，放在 [采购方法论](/methods/)。

## 已经在写

- [电子元器件与芯片](/categories/electronics/)：按存储、MLCC、MCU、模拟和电源、分立器件、连接器、晶振、线路板、显示拆开，另有能核对出处的历史案例。跨类文章仍保留。资料里的底稿数字截至 2026-10-20。
