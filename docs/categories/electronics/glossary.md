# 名词就这一句话

<!--@include: @/snippets/electronics-note.md-->

这些词正文里第一次出现时也会解释。这里收成一页，方便查。解释求能听懂，不是教科书定义。

## 公司和链条

- **原厂**：品牌方，比如德州仪器、村田。定价权大多在这一层。
- **授权代理**：原厂正式授权的分销商，可以帮你申请项目价。大联大、艾睿（Arrow）属于这一层。
- **独立分销、现货商**：没有这颗料的原厂授权，从市场上找货。断货时能救急，溢价和假货风险更高。
- **IDM**：自己设计、自己也有工厂的芯片公司，比如德州仪器、英飞凌。
- **Fabless**：只设计、生产交给代工厂的芯片公司，比如很多国产 MCU 和模拟芯片公司。
- **晶圆代工**：替别人生产晶圆的工厂，比如台积电、中芯国际。
- **封测**：把晶圆切成芯片、装上外壳并测好。日月光、长电科技在这一层。
- **Design-in**：设计阶段就把这家的料选进产品，并向原厂报备。后面才容易拿到项目价和供货优先级。
- **项目价**：原厂按你的项目给的特殊价格。代理账上的普通价，往往不是这个价。
- **EMS / ODM / OEM**：代工厂、替品牌设计并生产的厂、自己做品牌的厂。你的公司多半是其中一种，或者给他们供货。

## 料

- **MCU**：微控制器，板子上跑程序的那颗芯片。换牌往往要改软件。
- **存储**：DRAM、NAND、NOR、EEPROM 这些记忆体。价格波动通常最大。
- **DRAM**：掉电就没了的内存。电脑和服务器里的 DDR 属于这一类。
- **DDR4 / DDR5**：两代 DRAM。DDR5 更新。原厂把产能转向 DDR5 和 HBM 时，老的 DDR4 反而会缺、会涨。
- **HBM**：叠在一起、带宽很高的内存，主要给 AI 芯片用，非常占产能。
- **NAND**：断电还能留住数据的闪存，U 盘和固态硬盘里用。
- **模拟芯片**：处理连续电压电流的芯片，比如电源芯片、运放、接口。料号极多，单颗往往不贵。
- **功率器件**：MOSFET、IGBT、二极管、碳化硅这类，负责开关大电流。
- **MLCC**：片式多层陶瓷电容。板子上到处都是，单价很低，缺一颗也能停线。
- **成熟制程**：不那么先进的工艺。很多 MCU、模拟、功率芯片在这里做，常说 28 纳米及更老，也包括 8 英寸晶圆产线。
- **先进制程**：更细的工艺，比如 7 纳米及更新，主要做 AI 和高性能计算芯片。

## 采购动作

- **EOL**：停产。原厂宣布这颗料以后不做了。英文是 End of Life。
- **LTB**：最后一次购买。停产前还能下单的窗口。英文是 Last Time Buy。
- **PCN**：产品变更通知。原厂告诉你工艺、材料、封装或参数要改。英文是 Product Change Notice。
- **NCNR**：不可取消、不可退货。下了就要买。英文是 Non-Cancelable, Non-Returnable。
- **MOQ**：最小起订量。不够这个数，供应商不单独做。英文是 Minimum Order Quantity。
- **LTA**：长期协议。事先约定一段时间的量、价和供货规则。英文是 Long Term Agreement。
- **分配额度**：缺货时原厂不按你想买的量给，而按过去一段时间你实际提过多少来分。英文常叫 allocation。
- **AVL**：允许用在这颗产品上的料，要研发和质量签过字。没写进清单，仓库来了替代料也不能贴上去。
- **CoC**：合格证，用来说明这批货从哪条授权渠道出来。英文是 Certificate of Conformance。
- **订单出货比**：这一个季度新订单除以发出的货。大于 1，表示新单比出货多。英文是 Book-to-bill。
- **合约价**：大客户和原厂按月或按季谈定的价格。
- **现货价**：贸易商手里现货的成交价，通常比合约价波动快。
- **PMI**：采购经理指数。国家统计局每月公布，50 以上通常表示制造业比上月扩张。
- **第二来源**：同一功能再认一家厂，并且研发和质量签过字。只拿到样品、没写进可用清单，不算。
- **钽电容**：用钽粉做的电容。粉的多年合约有时是买了必须提，见 [钽电容案例](./cases/tantalum)。
- **晶振**：给出时钟的石英或模块。换料要核对频率、负载电容、ppm 和温度，不只是兆赫兹一样。
- **覆铜板**：做线路板的基材，铜箔、玻纤布和树脂压在一起。和线路板厂不是同一层。封装基板里更低膨胀的那种玻璃布，见 [T玻璃](/briefs/tglass)。
- **碳化硅**：一种做功率器件的材料，比普通硅更耐高压高温。认证通常比普通 MOSFET 慢。
