# 电子料历史案例

> 下面每篇都是真实历史事件，每条事实都附原文链接；标注“判断”的是经验推断，下单前请对照自己的料号。

下面每篇都是公开报道里能对上的事。结构一样：发生了什么，因果怎么串起来，价格和交期怎么动，当时买得好的和买砸的，最后一句教训。

买得好、买砸的，凡是没有点名某家工厂采购部的，都标成判断。数字只写原文里有的，不把几份报道捏成一个新数。

| 案例 | 主要落到哪类料 | 先记住的一句 |
| --- | --- | --- |
| [2017–2018 MLCC 缺货](./mlcc-2017-2018) | MLCC、电阻 | 几分钱的电容能停线；渠道库存堆到大半年就别再追 |
| [2018 存储见顶、2019 大跌](./dram-2018-2019) | DRAM、NAND | 跌的时候谈长约，山顶不要把高价签死 |
| [2021–2022 缺芯和三场意外](./shortage-2021) | MCU、车用芯片、晶振相关 | 一家工厂、一场停电，就能卡住一条车的线 |
| [2022–2023 鞭打效应和库存](./glut-2022-2023) | NAND、DRAM | 缺货时多下的单，松的时候会变成库存 |
| [2011 泰国洪水和硬盘](./thailand-hdd-2011) | 硬盘（和芯片不是一条链） | 产能集中在一个园区，洪水就是全球缺口 |
| [2011 东日本大地震](./tohoku-2011) | 晶圆、MCU、晶振 | 问清晶圆和封测在哪一座厂，再决定备多少 |
| [安世 / 闻泰，2024–2025](./nexperia) | 分立器件、小信号、MOSFET | 出口管制可以让「还在目录里的料」突然出不了货 |
| [HBM 挤占 DDR，2024–2026](./hbm-ddr) | DRAM | 原厂把晶圆让给 HBM 以后，老的 DDR 也会紧 |
| [钽电容和钽粉长约](./tantalum) | 钽电容 | 在山顶把原料签成必买，跌下来退不掉 |
| [2012 年美国参议院假货报告](./counterfeit-2012) | 所有要走现货的料 | 样品合格，不等于后面那一万颗是同一批 |

每篇末尾有一节「复盘」：发生了什么、传导链、领先信号、当时能不能看出来、和以前有什么不一样、采购动作。十篇收成方法，见 [产业链洞察](/methods/industry-chain-insight)。怎么把信号放进每周的看盘，见 [怎么读周期](../how-to-read-the-cycle)。各类料自己的打法在 [按料拆开](../index) 那一组里。
