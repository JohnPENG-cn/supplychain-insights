# PCB 和覆铜板

<!--@include: @/snippets/electronics-note.md-->

PCB 是印制线路板。覆铜板（常叫 CCL）是做板子的基材：铜箔、玻纤布、树脂压在一起。你向板厂下单，板厂向覆铜板厂买板材。两层不是同一家，交期也不是同一个数。

这一类没有像 DRAM 那样能每天公开核对的成交价。下面不编铜价、不编市场份额。读周期时把它和芯片分开看，见 [怎么读周期](../how-to-read-the-cycle)。

## 这条链怎么转，谁在定价

覆铜板采购会遇到建滔、生益、台光、松下、Isola、联茂、斗山这些名字。板厂则非常分散，汽车和通信的板子还会指定板材型号。这些是对料号用的名字，不是份额排行。本页没有核对过各家的市场占有率，不写百分比。

判断：普通双面板、四层板，板厂之间可以比价，覆铜板型号写进图纸后，成本跟着铜箔、玻纤和树脂走。报价有效期往往只有几天到几周。高速、高多层、HDI（更密的激光孔板）的定价权在已经做过程式和阻抗的那几家板厂，换厂要重新做首件。

你和板厂谈的是加工费加板材。板材涨了，板厂会改报价；板厂自己的产能满了，交期会拉长，即使铜价没动。两件事分开记。

## 周期通常怎么走，先看见什么

判断：PCB 的紧缺有两条线。一条是成本，铜和玻纤涨，报价变短、价格上调。一条是产能，汽车和服务器把高多层的产能占满，普通板也可能被挤。它不跟着 DRAM 合约价走。芯片缺货的年份，板厂可能很闲，因为整机排产下来了；芯片松动、整机抢产的年份，板厂可能先满。

领先信号：

1. 报价有效期。从一个月缩到一周，多半是板材价格不稳。
2. 板厂把交期从「天」改成「周」，并要求预付或提高最小面积。
3. 指定板材的交期。有时加工有空，覆铜板要等。
4. 你的改版频率。图纸没冻结，备板就是备废品。

没有把某一家研究机构的覆铜板价格表抄进来。要跟踪成本，用供应商写进合同的调价公式，加上你自己每次报价的台账。

## 新人容易踩的坑

- 只比板厂单价，图纸上的板材型号没有第二家能供。
- 在铜价高点把一年的板锁成固定价，或者反过来，不锁加工费、只口头答应随行就市。
- 安全库存做成立品板，改一次版就报废。
- 高多层只有一家板厂做过阻抗，量产后再找第二家，首件周期赶不上出货。
- 把芯片的 20 周交期抄来当板子的安全库存。

## 具体怎么买

判断。

**长约。** 能锁的是加工费和产能，板材单独约定调价。量的浮动大约 15% 到 20% 是谈判起点。写清：超了浮动怎么确认、提前几天可以改周计划、板材涨跌用哪一个公开铜价或双方确认的板材报价。没写公式，就不要签「价格按市场调整」。

**价格跟什么走。** 铜可以用双方指定的公开牌价，但要写明取价日、货币和加工费是否另计。玻纤和特种树脂常常没有你能免费核对的日指数，那就跟覆铜板厂给板厂的正式报价，并要求板厂把报价单附在调价函后面。不要引用看不清出处的「覆铜板价格指数」。

**安全库存。** 优先备已经冻结的通用板，数量覆盖板厂交期和你的发货波动。未冻结的新板不备。覆铜板由板厂备还是你备，写进协议：你备料要承担呆料，板厂备料要承担交期。

**第二来源。** 普通层数在量产前做两家板厂的首件。高多层和阻抗板，第二家的程式和切片要在旺季之前做完。板材第二来源要和硬件一起签，采购不能自行更换板材型号。

**停产和最后一次购买。** 停产的经常是某张旧版图纸或某种老板材，不是「PCB」这一类。旧版还有售后需求时，按剩余寿命算最后一次投板，并问板材是否还在产。板材停产要立刻通知硬件，因为改板材可能改阻抗。

**现货和贸易商。** 线路板很少像芯片那样在现货市场倒卖，风险更多是来路不明的余料、错版本、受潮的板。没有你的版本号和阻抗报告，不要收。假货链的总要求见 [参议院报告](../cases/counterfeit-2012)，板子上更常见的是错版本，不是打磨芯片。

## 下单前的检查清单

- 报价里板材和加工费分开了没有？有效期还有几天？
- 调价公式写了取价日没有？
- 图纸冻结了没有？没冻结就不要备成品板。
- 普通板有没有第二家首件？高多层的第二家做到哪一步？
- 指定板材本身的交期，是不是比加工更长？
- 旧版售后的最后一次投板算过了没有？
