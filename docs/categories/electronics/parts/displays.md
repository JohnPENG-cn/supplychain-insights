# 显示：面板、驱动芯片、背光

<!--@include: @/snippets/electronics-note.md-->

做整机或模组的采购，会同时碰到面板、驱动芯片、背光或触摸。这三样的交期不是一条。显示放进电子料这一章，是因为驱动芯片会跟着 [缺芯](../cases/shortage-2021) 走，面板的产能和价格则是另一套。

群智咨询、Omdia、TrendForce 的面板价格表多数要付费。本页不转载、不抄月度报价。没有核对过的面板美元价格，这里一个都不写。

## 这条链怎么转，谁在定价

面板厂常见京东方、华星光电、三星显示、LG 显示、友达、群创。驱动芯片常见集创北方、联咏、奇景、瑞鼎这些名字。背光还有 LED 和膜材。这些是对料号用的名字，不是份额排行，本页没有核对占有率。

判断：面板价格由面板厂和整机品牌按月或按季谈，中小客户拿到的往往是模组厂的包价，里面已经含玻璃、驱动和背光。你若只买模组，涨价函不会告诉你涨的是玻璃还是芯片。要会拆：问模组厂这颗料号的面板、驱动、背光分别还有多少周。

驱动芯片是半导体，周期和 [MCU](./mcu)、[模拟](./analog-power) 更近，晶圆厂紧的时候它会先拉长交期。面板的玻璃和产线投资周期更长，价格可以在需求差的时候跌很久，和存储不是同一根曲线。

## 周期通常怎么走，先看见什么

判断：

1. 模组厂把交期拆开。若只有驱动芯片变长，按芯片的保供办法处理，不要按「面板涨价」去锁一整年模组死价。
2. 面板厂的稼动和检修新闻。检修会减少供给，但是否涨价还要看品牌厂的库存。新闻标题不够，要看你这颗尺寸有没有被通知涨价。
3. 你的客户是否指定了某一家面板。指定了就没有第二来源，周期风险全部留在这一家。
4. 收费价格库可以买，但引用时打开原文。不要把别人整理的月度表格贴进内部汇报却不附链接。

::: unknown
本站没有核对 2024 到 2026 年任一尺寸面板的公开成交价，也不引用只在检索摘要里出现的「涨了百分之几」。需要价格时，用你自己的合同和供应商通知。
:::

## 新人容易踩的坑

- 把模组价当成面板价，驱动芯片缺货时去和面板厂谈，找错对象。
- 锁死一年模组价，里面的驱动芯片其实在另外涨，供应商后来改口按出货日计价。
- 换面板只比分辨率。亮度、接口、厚度、认证和模具都要重来。
- 现货模组没有原厂等级和批次，可能是降级屏或旧库存。
- 用存储周期决定显示的备货。两边可以一个在涨、一个在跌。

## 具体怎么买

判断。

**长约。** 模组长约把面板、驱动、背光的调价分开写。量的浮动大约 15% 到 20% 是谈判起点。只锁加工和背光、面板另议，或者三样都跟供应商的正式报价，不要合成一个死价又假装能跟指数。

**价格跟什么走。** 若公司已经订阅面板价格报告，可以在合同里写跟那份报告的某一尺寸，并写明差价和取价月。没有订阅，就不要在合同里写一个你打不开的指数名字。驱动芯片跟半导体的涨价函，规则同 [MCU](./mcu)。

**安全库存。** 模组占资金和仓库，只备已经冻结规格、交期长于出货周期的型号。面板尺寸一改，库存几乎没有别的产品能用。驱动芯片若可以单独买到，优先保证芯片，而不是把整块模组备满。

**第二来源。** 在开模前做两家模组的光学和结构。量产后替换要重做认证和模具。驱动芯片的第二来源属于改板或改固件，交给硬件，采购负责把样品交期排进计划。

**停产和最后一次购买。** 面板型号停产很常见。收到 EOL，成套算上驱动板和结构件，按产品剩余寿命做最后一次购买。只买面板、不买配套的驱动板，售后会缺一半。

**现货和假货。** 现货屏要防降级、翻新和错接口。要供应商的等级文件和你的图纸版本。检测至少包括点亮和外观。链条要求见 [参议院报告](../cases/counterfeit-2012)。

## 下单前的检查清单

- 报价拆得开面板、驱动芯片、背光吗？变长的是哪一段？
- 合同里的价格指数，公司自己打得开吗？打不开就不要写进合同。
- 规格冻结了没有？没冻结就不要备模组。
- 第二家模组的光学和结构做到哪一步？
- 停产是不是成套的？驱动板一起算了没有？
- 现货有没有点亮，等级文件在不在？
