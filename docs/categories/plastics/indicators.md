# 塑料采购能免费跟踪的指标

<!--@include: @/snippets/plastics-note.md-->

公开曲线告诉你树脂这一层冷热。你的 PC/ABS、PA66、PBT、线缆料、LCP 先动的，通常在自己的 ERP 和供应商邮件里。两套一起看。只看指数，会觉得外壳还没涨；只看一封邮件，会把一家改性厂的紧张当成全行业。

下面「怎么理解」都是判断。链接按这次能打开的页面来写。

## 先看你自己的系统

这五件比任何月度指数都接近你的线。本站不收集这些数据，只告诉你怎么记。

| 你看见什么 | 记在哪 | 对四类料意味着什么（判断） |
| --- | --- | --- |
| 报价有效期从 30 天收成 7 天，或写「按发货日计价」 | 报价台账：料号、旧有效期、新有效期、收到日期 | PC/ABS 和 PA66 改性牌号上，这通常早于新闻。线缆料如果同时不给增塑剂名字，把合规问题另起一行 |
| 代理或改性厂从「可以下」改成「要排配」「按上季提货分」 | 同一料号的沟通记录，留原话 | 这就是分配。问清基准是过去几个月的提货，还是对方口头说的紧张 |
| 某个牌号分配，旁边的牌号还能下 | 只记被分配的那个牌号，不要整类加库存 | 外壳常常是某个颜色或阻燃级。连接器常常是某个玻纤 PA66。LCP 常常是某个流动性牌号 |
| 改性厂要求这个牌号预付，或不接受月结 | 付款条件和料号绑在一起 | 预付只覆盖已经认过的牌号和已经确定的订单。不要为了「占产能」预付没认证的替代料 |
| 不可抗力函，或 PCN / 停产通知 | 函、影响的料号、生效日、你问回去的答复 | 函到当天就问：我的牌号在不在。PCN 改了基础树脂或增塑剂，按变更走，不要当普通涨价归档 |

每周把这五件过一遍的，是用量最大的那些料号：外壳 PC/ABS、连接器 PA66 和 PBT、用量最大的 PVC 或无卤电缆料、还在单供的 LCP 和 PPS。其余牌号一个月看一次就够。

## 四类料各看哪几个数

判断。

**PC/ABS 外壳。** 每月看树脂 PPI 的方向，用来问改性厂：基础树脂松了，加工费为什么不松。每周看你用量最大的两个颜色的报价有效期。有效期缩短，而 PPI 还在跌，更像这家厂的牌号或颜色紧，不是全行业紧。

**PA66 和 PBT 连接器。** 公开数据没有 ADN 的免费日价。看的是供应商有没有把「ADN、己二胺、装置停车」写进涨价函，以及玻纤 PA66 和 PBT 的交期是不是一起变长。一起变长，替代认证帮不上这个月；只有 PA66 变长，PBT 或 PA6 的既有认证就该拿出来用。认证状态以 AVL 为准。

**PVC 和无卤线缆料。** 树脂价用 PPI 和（若当旬有数）统计局的相关品种做背景。合规看全物质声明的日期，不看价格指数。无卤料的交期单独记，不要用 PVC 电缆料的交期去推断它。

**LCP 和 PPS。** 没有公开牌号价就不要造。看停产通知、PCN、以及这家厂还接不接新项目。战略库存的数量用剩余项目寿命乘用量，不用指数。

## 两个组合

**更像该去谈加工费：** 树脂 PPI 连续几个月回落，改性厂仍按高价报价，而且有效期恢复到 30 天，对方开始问你下季要不要多备。

**更像该保供、但不要重复下单：** 同一个牌号出现分配或预付，同时公开指数还没动。指数是月度的，你的料号可以先紧。保的是这个牌号已经确定的用量，不是把全年量锁成固定高价。
