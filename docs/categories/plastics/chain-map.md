# 塑料产业链一张图看懂

<!--@include: @/snippets/plastics-note.md-->

你下单的是一个牌号。付钱的时候，树脂、改性、色母和认证可能不在同一家。看懂层次，才知道涨价函该退给谁，以及为什么代理说「树脂涨了」时你仍要追问是哪一个牌号。

## 从上游到你的仓库

<ol class="chain">
  <li>
    <strong>油气和原料</strong>
    <span>乙烷、丙烷、石脑油、苯、丙烯。美国墨西哥湾丙烷有公开月价，见 [价格和交期](./price-and-leadtime)。大商所、郑商所的 PP、PE、PVC 期货这次不画，原因在 [先别当定论](./unknowns)。</span>
  </li>
  <li>
    <strong>单体和中间体</strong>
    <span>乙烯、丙烯、苯乙烯、氯乙烯、双酚 A、己内酰胺、己二腈（ADN）。连接器用的 PA66 卡在 ADN，不卡在「尼龙」这个词。欧洲 2022 年有一批装置是被天然气成本停掉的，见 [欧洲能源](./cases/europe-energy-2022)。</span>
  </li>
  <li>
    <strong>树脂厂</strong>
    <span>PP、PE、PVC、PS、ABS、PC、PA 的基础树脂。合约价和不可抗力函常常从这一层发出。你买 PC/ABS 或线缆料时，通常买不到这一层的原包装。</span>
  </li>
  <li>
    <strong>改性厂</strong>
    <span>玻纤、阻燃、增韧、色粉、合金。PC/ABS 外壳、连接器 PA66 和 PBT、不少无卤线缆料，是在这里变成你的料号。报价有效期、预付、某个牌号分配，先出现在这一层。</span>
  </li>
  <li>
    <strong>代理和贸易商</strong>
    <span>进口树脂、改配、现货。口风从「有货」变成「要排配」，往往比新闻早。现货能救急，也能把同一个牌号卖给你两次。</span>
  </li>
  <li>
    <strong>到你的工厂</strong>
    <span>注塑、挤出、线缆、连接器组装。图纸、UL、颜色和模具已经定了的料，换牌号不是改采购订单，是改认证。</span>
  </li>
</ol>

## 你买的四类，分别卡在哪一层

判断。

| 你买的 | 日常报价在哪 | 真正会断的那一层 | 换料要动什么 |
| --- | --- | --- | --- |
| PC/ABS 外壳 | 改性厂的颜色、阻燃、冲击牌号 | PC 或 ABS 基础树脂一紧，改性厂就缩有效期 | 同模、同色、同阻燃等级，研发签字 |
| PA66 / PBT 连接器 | 改性厂的玻纤和阻燃牌号 | PA66 再往上是 ADN；PBT 紧的时候会变成替代去处，自己也会紧 | 端子保持力、耐热、吸湿，客户常要重认 |
| PVC / 无卤线缆料 | 电缆料厂的配方号 | PVC 树脂和增塑剂；无卤还卡阻燃填料。法规卡的是配方，不是吨价 | 全物质声明、阻燃和柔软，整根线重测 |
| LCP / PPS | 往往一家原厂或一家改性 | 特种树脂本身，第二家很少 | 高速连接器还要信号和回流焊，按年排 |

通用树脂那一页写的是第三层。工程塑料、线缆、特种料三页写的是你下单的那一层。

## 改性厂让得动的，通常不是树脂

判断：改性厂能谈的是加工费、色差、起订量和交期。基础树脂的合约价不在他柜台上。你把目标价压到「比树脂指数还低」，对方要么缩短报价有效期，要么改用你没认过的基础牌号。后一种要当成变更，不是便宜。

::: fact
美国树脂价格指数能公开跟踪，改性牌号没有同等的公开序列。BLS 的 PCU325211325211 是「塑料材料与树脂制造」，2026-09 为 327.535（[BLS API](https://api.bls.gov/publicAPI/v2/timeseries/data/PCU325211325211)）。不要把这个数写成你们的 PC/ABS 或 PA66 报价。
:::

不可抗力函从树脂厂发出以后，改性厂转给你的常常是「这个颜色暂不接单」。问的时候把两层分开记：树脂厂停的是哪套装置，改性厂停的是你的哪一个牌号。
