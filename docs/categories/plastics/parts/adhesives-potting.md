# 胶粘剂与灌封料

<!--@include: @/snippets/plastics-note.md-->

环氧、有机硅、UV 胶、灌封料，配方在供应商手里。第二来源几乎不能靠规格书「参数接近」完成。这一页写短。

## 指数只能当背景

::: fact
美国胶粘剂制造的生产者价格指数 PCU325520325520，2022-06 为 337.558，2026-09 为 395.605。涂料及相关产品 PCU325510325510，2026-09 为 447.930（[胶粘剂](https://api.bls.gov/publicAPI/v2/timeseries/data/PCU325520325520)、[涂料](https://api.bls.gov/publicAPI/v2/timeseries/data/PCU325510325510)）。同一段里，树脂指数从 2022-06 的 380.764 回落到 2026-09 的 327.535。
:::

判断：树脂指数回落时，胶和涂料的行业指数仍在往上。灌封料的报价不要按树脂 PPI 的百分比去砍。这两个 PPI 也不是某一个配方号的价格。

## 做什么

1. 合同和 BOM 写死配方号和版本，不写「同等环氧」。
2. 收到 PCN 或停产：按剩余项目寿命做最后一次购买，数量由工程签字。步骤同 [特种料](./specialty-plastics) 的最后一次购买，因为同样不可随手替换。
3. 想上第二家：要重做固化、绝缘、耐热和与壳体的粘接。没做完之前，缺货只走原配方的分配或最后一次购买，不走现货「看起来一样的胶」。
4. 供应商要求预付或缩短报价有效期：只覆盖已经在用的配方号和已确定的订单。

没有单独的灌封料历史案例。装置和能源冲击若影响基础化工，看 [欧洲能源](../cases/europe-energy-2022)，再问供应商这颗配方的原料在不在停产名单里。
