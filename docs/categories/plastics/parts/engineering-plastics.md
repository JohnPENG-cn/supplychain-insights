# 工程塑料：PC/ABS、PA66、PBT

<!--@include: @/snippets/plastics-note.md-->

这一页写两类你最常碰到的工程塑料：外壳的 PC/ABS，连接器的 PA66 和 PBT。POM 只在名词里提一句，不展开。基础树脂的冷热在 [通用树脂](./commodity-resins)，这里写改性之后的料号。

## 外壳：PC/ABS

PC/ABS 是聚碳酸酯和 ABS 的合金，再加颜色、阻燃、增韧。你看到的料号，多半是改性厂的，不是树脂厂的合约牌号。

判断：涨价函要拆开问。ABS 松的时候，PC 和色母可以仍紧。对方说「塑料都在涨」，让他写这次动的是 PC、ABS 还是加工费。写不出，这张函只作线索，不作全行业结论。

::: fact
能免费连续看到的，是美国树脂制造的价格指数，不是 PC/ABS 牌号价。PCU325211325211 在 2022-06 为 380.764，2026-09 为 327.535（[BLS](https://api.bls.gov/publicAPI/v2/timeseries/data/PCU325211325211)）。指数回落之后，改性报价会不会跟着降，看你的报价单，不看指数自动跳。
:::

和外壳有关的历史，是成本背景，不是一次「PC/ABS 缺货」的专门案例：树脂指数的回落见 [2022–2023](../cases/ppi-retreat-2022)，通用树脂偏松见 [中国过剩](../cases/china-glut-2024)。不要把这两篇改写成外壳料的交期统计。

领先信号，按出现的顺序记：

1. 用量最大的颜色，报价有效期变短。
2. 这个颜色要分配，别的颜色还能下。
3. 改性厂要求该牌号预付。
4. 来了 PCN，基础树脂或阻燃体系要换。

可互换，只发生在 AVL 里已经有的另一家、同阻燃、同色差、同模具已经试过。没试模的「参数接近」，不能在缺货那周顶上。第二家改性厂的认证放在指数回落、有效期恢复的季度，步骤在 [实战打法](../playbook)。

## 连接器：PA66 和 PBT

PA66 的上游故事是 ADN。2018 年年中，尼龙 66 比 18 个月前贵了 50% 以上；全球 ADN 产能大约 38 亿磅，四家主要生产商；文中提到的替代是 PA6、PBT、PPA（[Plastics Technology，2018-11-30](https://www.ptonline.com/articles/nylon-66-pricing-supply-issues-spur-processors-to-consider-alternatives)）。全文和当时能不能看出来，在 [PA66 案例](../cases/pa66-adn-2018)。

PBT 在那篇文章里是替代方向，在你的 BOM 里常常已经是连接器本体。两件事要分开：用 PBT 去替 PA66，和你本来就在买的 PBT 会不会一起紧。一起紧的时候，替代表帮不上这个月。

判断：连接器换材料不是改采购文本。端子保持力、吸湿后的尺寸、耐热、阻燃，以及客户指定，都可能把「PA6 更便宜」挡在量产之外。2018 年的报道也写，真正换掉的并不多。所以认证要在松的时候做完，把结果写进 AVL。

领先信号：

1. 涨价函里出现 ADN、己二胺或「尼龙 66 装置」。
2. 某个玻纤、阻燃牌号分配，未增强的牌号还能下。
3. 改性厂要求 PA66 预付，同时 PBT 的交期也变长。这时两列都要保已确定的订单，不要只囤 PA66。
4. 不可抗力函。当天用邮件问：我的料号在不在这套装置上。

长约写数量区间和可以向下的价格。不要在公开报道已经写出大涨之后，再签一年固定高价。加工费和树脂分开。玻纤若另涨，让对方单独列，不要藏进「尼龙涨了」。

## 下单前看这六格

- 这颗是外壳 PC/ABS，还是连接器 PA66 / PBT？
- 第二家有没有进 AVL，试模或端子试验做了没有？
- 报价还剩几天？跟哪一个公开序列调价，写进合同了没有？
- 被分配的是整个树脂，还是一个颜色、一个玻纤牌号？
- 全物质声明和阻燃等级的日期还在不在有效期内？
- 现货或贸易商的货，有没有改性厂或原厂的批次？
