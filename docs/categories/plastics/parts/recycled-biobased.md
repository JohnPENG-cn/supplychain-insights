# 再生料与生物基

<!--@include: @/snippets/plastics-note.md-->

有的外壳会指定 PCR-PC、PCR-ABS，或一小部分生物基。这一页写短。价格不编。

## 再生料要认的是批次，不是名字

::: fact
Plastics Recyclers Europe 2024-02-26 写道，再生塑料进口上升，正在冲击欧盟回收业；文中称 2023 年欧盟塑料废物出口增加 18%。18% 出现在这篇新闻里，脚注指向的研究本次没有另打开（[PRE](https://www.plasticsrecyclers.eu/news/study-confirms-rising-imports-of-recycled-plastic-threaten-eu-industry/)）。
:::

::: fact
欧盟委员会 2025-12-23 的问答写：欧洲塑料回收产能的增长从 2021 年的 17% 降到 2022 年的 10%、2023 年的 6%；到当年年底产能将下降 100 万吨。委员会将修订海关编码，用来区分原生塑料和再生塑料，包括食品接触材料，并加强对欧盟内外回收装置的审核（[问答 PDF](https://ec.europa.eu/commission/presscorner/api/files/document/print/en/qanda_25_3152/QANDA_25_3152_EN.pdf)）。
:::

《新闻报》2024-05-18 的文章标题和导语指控来自亚洲的「假旧塑料」挤占欧洲再生料市场（[Die Presse](https://www.diepresse.com/18475514/sogar-der-abfall-aus-asien-ist-gefaelscht)）。这是媒体报道里的指控，不是判决，也不是你们来料的检测结果。细节和界限在 [再生料案例](../cases/recycled-imports)。

## 做什么

1. 合同写明再生含量的定义、认证和批次追溯。只有「PCR」两个字，没有批次，按资料不全。
2. 来料按批抽检你们和客户约定的项目。样品合格不能代替这一批。
3. 供应商更换回收来源，走 PCN。外壳的颜色、冲击和阻燃可能一起变。
4. 原生料价格下跌时，再生料不一定更便宜。便宜的那一批，更要核对是不是原生料冒充。冒充与否以你们的检测和文件为准，不以一篇报纸为准。

生物基若出现在供应商的替代建议里（例如 2012 年赢创提到的 VESTAMID Terra），把它当成另一种材料做认证，不要当成原来的 PA12 或 PC 的直接替换（[赢创新闻稿](https://publications.evonik.com/en/media/press-releases/corporate/attachment/11053?rev=1)）。
