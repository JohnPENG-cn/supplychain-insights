# 特种工程塑料：LCP 和 PPS

<!--@include: @/snippets/plastics-note.md-->

这一页写 LCP 和 PPS。高速连接器、耐热结构件会用到。PEEK、PA12 不是这四类里的用量主力，PA12 只作为「一座装置卡住全球」的公开例子，链到 [赢创案例](../cases/evonik-pa12-2012)。

本站没有核对到可以写成案例的 LCP 或 PPS 价格、交期或一次停产。下面不编这些数字。缺的公开事件记在 [先别当定论](../unknowns)。

## 为什么不能等信来了再找第二家

判断：LCP 和 PPS 的供应商比 PC/ABS 少。高速连接器还要信号完整性和回流焊，客户往往指定牌号。认证从送样到批准，按项目算常常是按年，不是按周。这个「按年」是采购经验，不是一份公开的平均周期统计，所以页面不写死成某一个周数。具体周数问你们的质量和客户，写进项目计划。

赢创 2012 年 3 月 31 日的火，烧的是 PA12 的单体装置，不是 LCP。能借用的只有这一条：单体或树脂只有一条主供应时，复产以季度计，替代认证如果当时还没做，当季帮不上（[赢创新闻稿](https://publications.evonik.com/en/media/press-releases/corporate/attachment/11053?rev=1)）。LCP、PPS 按这个样子准备，不要等自己也上了新闻。

## 战略库存怎么算

只对同时满足这三条的料号建战略库存：单供、客户指定或认证很长、缺了会停连接器或整机。三条缺一条，优先做第二来源，而不是加库存。

数量：

**剩余还要生产的月份 × 月用量 ×（1 + 你们自己的报废率）**

月用量用过去出货，不用销售预测的高峰。报废率没有历史就不乘。写上牌号、批号规则和保质期。过期的特种料和缺料一样不能上线。

这不是「先买一年看看」。一年如果项目只剩一个季度，多出来的料会变成库存；项目还有三年而你只买了一个月，停产信来了又不够。

## 最后一次购买

停产或 PCN 写明最后购买日之后：

1. 工程和使用部门在信上签字确认数量，采购不单独拍板。
2. 数量一次下完。最后购买常常不能取消、不能退。
3. 下单前核对模具和客户文件是否还用这个牌号。已经决定改版的，不要按旧寿命买满。
4. 第二来源即使来不及在最后购买日之前批准，认证也不要停。批准之后，剩下的战略库存用来过渡，不用来阻止切换。

## 不能互换的地方

判断。

- LCP 和 PPS 不能因为都「耐热」就互换。高速连接器换 LCP 的流动性或换 PPS，要有信号和焊接的记录。
- 同一化学名、不同流动性牌号，在薄壁连接器上不是同一种料。
- 贸易商的 LCP 现货，没有原厂批次和湿敏说明的，不当成战略库存。

## 领先信号

没有价格指数。能记的是：

- 这家厂不再接新项目，只供老料号。
- 报价从年度变成「一单一议」，或要求预付。
- PCN 改了聚合工艺或停了一个流动性牌号。
- 代理从「有库存」改成「要排配」。

这四件出现任何一件，就把那颗料号放进周会的单供清单，而不是等停产信。
