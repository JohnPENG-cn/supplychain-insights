# 含氟聚合物与 PFAS

<!--@include: @/snippets/plastics-note.md-->

高频线、密封件、一部分电池粘结剂会用到 PTFE、FEP、PVDF。它们属于含氟聚合物，落在 PFAS 这个大类的讨论里。这一页只保留采购要做的事，行情不编。

## 已经发生的和还没变成禁令的

::: fact
3M 在 2022-12-20 宣布，将在 2025 年底前退出全部 PFAS 制造，并努力在产品组合中停止使用 PFAS。新闻稿写，退出范围包括含氟聚合物、含氟流体和基于 PFAS 的添加剂；当时制造类 PFAS 的年净销售额大约 13 亿美元，EBITDA 利润率大约 16%（[3M，2022-12-20](https://news.3m.com/2022-12-20-3M-to-Exit-PFAS-Manufacturing-by-the-End-of-2025)）。
:::

::: fact
3M 现状页写，PFAS 制造退出已在 2025 年底完成；产品组合里停止使用 PFAS 仍在推进，供应链中不是 3M 制造的含 PFAS 产品还在评估。该页现网页这次被拦截，句子核对自 2026-10-19 的存档（[存档](http://web.archive.org/web/20261019214633/https://www.3m.com/3M/en_US/pfas-stewardship/uses-applications/)）。
:::

::: fact
ECHA 新闻稿 ECHA/NR/23/04（赫尔辛基，2023-02-07）写：丹麦、德国、荷兰、挪威、瑞典主管机关于 2023-01-13 向 ECHA 提交限制提案，范围大约 1 万种 PFAS；若不采取措施，主管机关估计未来 30 年大约 440 万吨 PFAS 会进入环境。委员会将形成意见，再由欧盟委员会和成员国决定。现网页被拦截，句子核对自 2026-04-18 的存档（[存档](http://web.archive.org/web/20260418194701/https://echa.europa.eu/-/echa-publishes-pfas-restriction-proposal)）。
:::

判断：提案不是你料号上已经生效的禁令。3M 退出是供应商的时间表，别的含氟聚合物供应商不会自动同一天停。盘点仍要做，因为客户和法规问的是「料里有没有」，不是「提案过了没有」。时间线在 [PFAS 案例](../cases/pfas-exit)。

## 做什么

1. BOM 里搜 PTFE、FEP、PVDF、以及供应商用的商品名。每颗记：用在高频线、密封还是粘结剂，供应商是谁，有没有第二家。
2. 问供应商两件事，并要求书面回复：还会供到什么时候；替代路线叫什么、认证要多久。没有回复日期的，周会继续挂着。
3. 替代没有批准之前，按 [特种料](./specialty-plastics) 的办法算最后一次购买和过渡库存。不要因为新闻标题把所有含氟件都加成一年库存。
4. 全物质声明里出现 PFAS 而你的清单没有这颗料：先补清单，再决定是否换。不要在声明和 BOM 不一致时继续下单。
