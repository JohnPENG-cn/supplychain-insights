# 塑料实战打法

<!--@include: @/snippets/plastics-note.md-->

先认阶段，再选动作。阶段看错，下面的表会用反。阶段怎么认，用 [指标](./indicators) 里的公开曲线和你 ERP 里的五件，不要只用一篇新闻的标题。

电子料那套锁价、分配、第二来源的总原则在 [电子料实战打法](/categories/electronics/playbook)。这一页只写塑料，而且先写你买得最多的四类。

## 四个阶段

| 阶段 | 你看到什么 | 四类料做什么 |
| --- | --- | --- |
| 松、树脂指数在回落 | PPI 从高点下来，改性厂把有效期放回 30 天，还主动问你要不要多备 | 压加工费。做 PC/ABS 第二家改性和 PA66 的 PA6/PBT 认证。线缆把全物质声明补齐。LCP/PPS 如果还是单供，现在开认证，不要等下一封停产信 |
| 刚稳住 | 指数不再跌，有效期开始变短，但还没有分配 | 给改性厂一个季度的滚动预测。价格写「树脂方向 + 加工费」，加工费单独谈。不把全年量锁成固定高价 |
| 紧、某个牌号在分配 | 报价有效期变成几天，要求预付，或来了不可抗力函 | 保这个牌号已经确定的订单。问函里有没有你的牌号。同一牌号不要向三家贸易商各占一笔 |
| 信来了要停产 | PCN 或停产，写明最后购买日 | LCP、PPS、单供的灌封配方：按剩余项目寿命算最后一次购买。外壳和线缆优先换已经签字的第二家，而不是先囤一年 |

## PC/ABS 外壳

判断，按这个顺序做。

1. 把用量最大的颜色和阻燃等级列出来。每个料号写：改性厂、基础树脂牌号（若对方肯写）、UL 黄卡、模具是否已定。没有 UL 或没有颜色样的，不算第二来源。
2. 松的时候请第二家改性厂打样，用现有模具试模。试模结果由研发签字进 AVL。缺货那一周才送样，这个月用不上。
3. 报价单拆成两行：基础树脂怎么调，加工费是多少、几个月不动。对方说「随行就市」又不写跟哪一个公开价格，就不要口头答应。跟 BLS 指数也可以，但要写明序列号和取数日。BLS 是行业指数，不是这个颜色的价，只能做调价的参照，不能当成成交价。
4. 有效期缩短到 7 天：只对未来 4 到 8 周已经排产的外壳下单，不把下半年的颜色一次锁死。4 到 8 周是谈判用的窗口，不是公式。
5. 某个颜色被分配、别的颜色还有货：加库存只加被分配的那个颜色，而且数量不超过已确定订单。不要因为「ABS 要涨」把所有外壳料都加两个月。

PC 和 ABS 不是同一种紧法。ABS 更靠近通用树脂，中国聚烯烃和苯乙烯松的时候，ABS 往往先松。PC 还受双酚 A 和装置影响，公开免费日价本站没有，不编。谈 PC/ABS 时让对方说明这次涨的是 PC、ABS 还是色母。说不清，就不当成全行业涨价。

## PA66 和 PBT 连接器

这一类和 [PA66 案例](./cases/pa66-adn-2018) 绑在一起看。2018 年的教训是：涨价已经发生，真正换料的并不多，因为尺寸、吸湿和认证过不了。

1. 连接器 BOM 分成三列：PA66、PBT、其他（LCP、PPS、PA6）。每列写清玻纤含量和阻燃。没有这三列，紧的时候会把所有「尼龙」都加成库存。
2. 松的季度做替代认证，不是紧的季度做。PA66 的公开替代方向是 PA6、PBT、更高一档的 PPA。PBT 若已经是现用料，它不是无限的避难所，认证时把它自己的交期也记上。
3. 换料最少做：端子保持力、耐热、吸湿后的尺寸、阻燃。连接器若是客户指定，认证周期按客户的流程，不按改性厂说的「两周可以换」。
4. 年度协议只锁一个数量区间，价格允许向下。2018 年那种「比 18 个月前贵 50%」的位置上，不要再签 12 个月固定高价。50% 是那篇文章里的事实，不是你下一张订单的涨幅。
5. 涨价函写 ADN 或装置停车：当天问这个玻纤牌号的分配比例，以及 PBT 或 PA6 的已认证牌号还有没有货。没有已认证牌号，这个月只能保 PA66，认证排到下一轮。
6. 预付可以谈，范围是未来一个认证周期内、已经进 AVL 的牌号。预付给贸易商去「找 PA66」，按现货风险处理，要链条和检测。

## PVC 和无卤线缆料

和 [邻苯案例](./cases/rohs-phthalates-2019) 一起看。

1. 本月把线缆 BOM 扫一遍：DEHP、BBP、DBP、DIBP 有没有出现在全物质声明里。没有声明的，向电缆料厂要，给一个回复日期。声明过期超过一年的，当没有。
2. 2019-07-22 之前已上市设备的维修线缆，和现在新机型的线缆，分两个库位。法令对前者的线缆和备件有豁免，混在一个料号里会在客户审厂时说不清。
3. 报价写「不含邻苯」但没有替代增塑剂名称、没有第三方报告：退回，不比价。换增塑剂走 PCN，要重测柔软、析出和阻燃。
4. 无卤料和 PVC 电缆料分开谈。无卤紧的时候，不要用 PVC 的吨价去压无卤，也不要在没做燃烧试验时把 PVC 护套改成无卤。
5. 用量最大的一个 PVC 电缆料牌号，保持两家电缆料厂，配方号冻结。第二家只停留在「可以报价」，仓库来了货也不能用。
6. 树脂涨价函到了：可以谈树脂部分。配方和加工费另写。哈维那一轮的教训是，PVC 合约涨幅和行业 PPI 不是同一个数，见 [哈维案例](./cases/harvey-2017)。

## LCP 和 PPS

公开案例里没有一次核对过的 LCP 或 PPS 单独行情。动作按单供特种料来写，参照的是 [赢创 PA12](./cases/evonik-pa12-2012)：一座单体装置可以卡住下游，认证又来不及。

1. 列出每一颗 LCP 和 PPS：供应商、年用量、是否单供、客户是否指定、上次认证是哪一年。这张表没有，战略库存就是拍脑袋。
2. 还是单供的，在树脂不紧的季度启动第二来源。判断：连接器客户的认证常常要一年以上。这个年限是经验，不是某份公开统计，所以不写死成「必须 14 个月」。排期问客户质量，写进项目计划。
3. 战略库存只覆盖：剩余项目月份 × 月用量 ×（1 + 你们自己的报废率）。报废率用你们的历史，没有历史就先不要乘一个看起来精确的百分比。库存要注明牌号和保质期，特种料过期一样报废。
4. 停产信或最后购买日到了：数量由工程和使用部门签字，不由采购单独决定。签过的数量一次下完，不分成「先买一半看看」。最后购买常常不可退。
5. 不要用 PPS 直接替换 LCP 的高速连接器，除非信号和回流焊已经有报告。外观能注塑，不等于客户认。

## 紧的时候不要做的事

判断。

- 同一牌号向三家贸易商各付一笔订金。货可能是同一批，库存会在松的时候回到你仓库。
- 用树脂 PPI 的涨幅，要求所有塑料件同比例涨价或降价。改性、色母、认证费不在那个指数里。
- 不可抗力函一到，就把所有塑料的安全库存天数调高。先问牌号。不在函里的料，按普通交期。
- 为了完成降价指标，在分配期间把提货降到零。下次分配常常按过去提货。该提的稳定周量要提，多出来的预测不要提。

## 松的时候要留下的记录

每一颗外壳、连接器、线缆、LCP 料号留四格：第二来源签了没有，报价有效期是几天，全物质声明的日期，最后一次购买是否还开着。下一次紧的时候，周会只看这四格还是空的料号。
