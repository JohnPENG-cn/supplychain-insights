# 塑料历史案例

> 下面每篇都是真实历史事件，每条事实都附原文链接；标注“判断”的是经验推断，下单前请对照自己的料号。

和外壳、连接器、线缆最相关的，先看 PA66 和邻苯。寒潮、飓风、欧洲能源和指数回落，是树脂成本怎么传到改性厂。LCP 和 PPS 没有单独的公开事件，单点装置看赢创 PA12。

买得好、买砸的，没有点名某一家工厂采购部的，都标成判断。数字只写打开过的原文或档案馆存档里有的，不把几份报道捏成一个新数。

| 案例 | 主要落到哪类料 | 先记住的一句 |
| --- | --- | --- |
| [PA66 / ADN，2017–2019](./pa66-adn-2018) | 连接器 PA66、PBT | 涨了 50% 以后再认证替代，当季来不及 |
| [RoHS 四种邻苯，2019](./rohs-phthalates-2019) | PVC 和无卤线缆料 | 0.1% 从 2019-07-22 起适用，维修线和新机型分开 |
| [得州寒潮，2021](./texas-freeze-2021) | 通用树脂，再传到改性和线缆 | 2 月到 3 月指数的跳升，大于同期丙烷 |
| [哈维飓风，2017](./harvey-2017) | PVC 树脂、PP | 现货可以跳 11 美分，行业指数只缓缓抬 |
| [欧洲能源，2022](./europe-energy-2022) | 尼龙链、欧洲装置 | 额外能源成本 32 亿欧元，产量指数掉到 76.4 |
| [树脂 PPI 回落，2022–2023](./ppi-retreat-2022) | 所有跟树脂走的料 | 高点 380.764 之后回落，原因不要写成单一一条 |
| [中国聚烯烃过剩，2023–2024](./china-glut-2024) | PP、PE，以及外壳里的 ABS | 旬价和台塑营收可以看，期货不画 |
| [赢创 PA12，2012](./evonik-pa12-2012) | 特种料的单点风险 | 一座单体装置，复产按季度 |
| [熔喷布，2020](./meltblown-2020) | 恐慌超买 | 一条线至少 5 到 6 个月，报价来自销售人员 |
| [PFAS：3M 退出](./pfas-exit) | 含氟聚合物 | 退出是 3M 的时间表，提案还不是禁令 |
| [再生料进口，2024–2025](./recycled-imports) | 再生外壳料 | 海关编码和审核是政策，假料指控是报纸 |
