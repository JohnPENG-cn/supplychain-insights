# 塑料名词就这一句话

<!--@include: @/snippets/plastics-note.md-->

解释求能听懂，不是教科书定义。

## 料

- **PP、PE、PVC、PS、ABS**：通用树脂。ABS 常进 PC/ABS 外壳。PVC 树脂再配成线缆料。详细在 [通用树脂](./parts/commodity-resins)。
- **LLDPE**：线性低密度聚乙烯。统计局旬报里的规格写成熔融指数 2 的薄膜料，不是你的所有 PE 件。
- **拉丝料**：统计局聚丙烯旬价用的规格，不是所有 PP 牌号。
- **PC**：聚碳酸酯。和 ABS 做成 PC/ABS，常用于外壳。
- **PC/ABS**：聚碳酸酯和 ABS 的合金，外壳常用。报价多半是改性厂的颜色和阻燃牌号。
- **PA66、PA6**：两种尼龙。PA66 的上游瓶颈常在 ADN。PA6 是常见替代方向，不是随手能换。
- **PBT**：聚对苯二甲酸丁二醇酯。连接器常用，也是 PA66 的替代方向之一。
- **PPA**：更高耐热的一类尼龙。PA66 替代名单里会提到，认证通常更长。
- **POM**：聚甲醛，轴套、齿轮多见。不在这次写深的四类里。
- **LCP**：液晶聚合物。高速连接器常用，供应商少。
- **PPS**：聚苯硫醚。耐热结构件和一部分连接器。不能凭手感替换 LCP。
- **PEEK、PA12**：更贵或更专的特种料。PA12 的公开事故见 [赢创案例](./cases/evonik-pa12-2012)。
- **ADN**：己二腈，做 PA66 的关键中间体。
- **CDT**：环十二碳三烯，做 PA12 的单体原料。
- **PTFE、FEP、PVDF**：含氟聚合物。高频线、密封、电池粘结剂里会碰到。见 [含氟聚合物](./parts/fluoropolymers-pfas)。
- **无卤**：不靠卤素阻燃。线缆里常是聚烯烃加无机填料，和 PVC 电缆料不是同一个配方。
- **邻苯**：这里主要指 DEHP、BBP、DBP、DIBP。RoHS 限的是这四种，不是所有增塑剂。
- **再生料、PCR**：用过再造的塑料。名字不能代替批次追溯。
- **改性**：在基础树脂里加玻纤、阻燃、增韧、颜色。ICT 采购看到的料号，多半在这一步之后。

## 采购动作

- **报价有效期**：这张价还能用几天。突然变短，是紧的信号。
- **分配**：不按你想买的量给，按规则分。英文常叫 allocation。
- **不可抗力**：合同里约定的免责事件。收到函先核对你的牌号在不在范围内。
- **PCN**：产品变更通知。树脂、增塑剂、配方改了，都算。
- **FMD**：全物质声明。线缆料用来看有没有邻苯和别的限用物质。
- **AVL**：允许用在这颗产品上的料，要研发和质量签过字。
- **LTB**：最后一次购买。停产前还能下单的窗口。
- **战略库存**：为单供、认证很长的料准备的货。数量要能算出来，不是「多买一点」。
- **PPI**：生产者价格指数。本站用的美国树脂序列是 PCU325211325211。

## 不要混的两个指数

- **PCU325211325211**：塑料材料与树脂制造。案例图用的是这个。
- **PCU3252113252111**：热塑性树脂分项。数值不一样，不能把一篇文章里的点和另一个序列对上。
