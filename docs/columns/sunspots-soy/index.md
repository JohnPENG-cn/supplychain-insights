# 太阳黑子和大豆

<p class="brief-meta">更新 2026-11-26</p>

有人用太阳大约 11 年一轮的黑子，来讲大豆哪一年会丰收。这一栏把这个说法拿公开数据算一遍。数字带来源，判断和事实分开。太阳黑子没有放进看板。库存和厄尔尼诺的当月读数在 [大豆周期信号](/dashboard/soy/)。
