# 半导体周期

<p class="brief-meta">更新 2026-11-10</p>

代理常把四类完全不同的厂说成「半导体都紧了」。这一栏不跟这句走。每篇把能对上财报的公司分成几组，组与组之间不合并，也不下「全行业」结论。数字带来源，判断和事实分开。

<!--@include: @/snippets/semi-cycle-note.md-->

## 每篇怎么读

- 开头是买方正在问的那一句。
- 接着说明这张图怎么做：哪几家、什么口径、哪些季度不能同比。
- 事实先写数据和简单的图，判断单独放在后面。
- 最后留一节「现场观察」。还没补的，会明说。

单家公司最新一季的账本、电话会和谈判筹码，在 [采购人视角读财报](/columns/company-lens/)。各类料该看哪个信号，在 [怎么读周期](/categories/electronics/how-to-read-the-cycle)。这一栏看的是二十年里这四组账本自己的节奏。

## 已经发布

### [用二十年财报看半导体：库存大约四年走一轮](./twenty-years)

<p class="brief-meta">发布 2026-11-10 · 数据从 2005 年到 2026 年第三季度</p>

代工、封测、模拟/MCU、设备四组，库存下行的谷底大致落在同一批年份：2009、2011–2013、2015–2016、2019、2023。间隔大约三年半到四年。七到十年的投资周期，在「多久来一次」上看不清，只看得到深谷和扩产潮的振幅。2026 年第三季度四组不是同一步。数据集可以下载。
