# 采购人视角读财报

<p class="brief-meta">更新 2026-10-31</p>

做财报解读的人，大多关心股价。这一栏关心的是另一件事：供应商的账本，说明我们下一轮谈判手里有什么。每篇挑一家公司，只回答三个问题：谈判筹码在谁手里，周期走到哪一段，采购现在该做什么。用大白话写，数字带原文链接，判断和事实分开。

<!--@include: @/snippets/lens-note.md-->

## 每篇怎么读

- 开头一句话说清：这家公司是谁、这篇要回答哪个采购问题。
- 中间挑三个左右的数字。每个数字先用一句话翻译成人话，再说它对买方意味着什么。
- 后面是判断：筹码、周期、该怎么做。最后留一节「现场观察」，写一线看到的情况。还没补的，会明说。

和其他栏目分开：[产业链情报中心](/briefs/) 找的是一条链上卡住的那一层；[历史案例](/categories/electronics/cases/) 讲已经发生完的事；这一栏只读一家公司最新一期的账本。过了发布日期，就当历史看。
