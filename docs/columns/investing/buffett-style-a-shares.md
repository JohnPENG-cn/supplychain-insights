# A股有没有“巴菲特式”股票？有，但570只里只有20只

<p class="brief-meta">长期投资笔记 · 发布 2026-11-10 · 数据截至 2026-11-09 收盘（北京时间）</p>

<!--@include: @/snippets/invest-note.md-->

::: judgment 先说结论
1. **有，但很少。** 今天的沪深300、中证500、中证红利成分股里，有完整10年行情的570只，同时过了“涨得好、分红稳、还在涨、赚钱能力强”五道门槛的只有 **20只**。
2. 这20只把分红再买回去，10年平均每年赚 **10%到26%**。茅台18.8%、美的16.7%、福耀16.0%、招商银行13.6%、长江电力12.3%，和巴菲特持有的可口可乐（11.9%）、美国银行（14.3%）、雪佛龙（11.8%）在同一档。同期沪深300全收益只有 **4.3%**。
3. 觉得“分红股股价不行”，一是只看了股价、**没把分红算进去**，二是 **2021年买得太贵**：茅台那时市盈率接近60倍，那个月底买入，算上分红到今天还亏20.5%。
4. 名单集中在白酒、家电、汽车零部件、银行、水电和几个周期行业；而且是拿今天的成分股往回看，结果偏乐观。
:::

## 一、问题从哪来

前几天我把茅台、苏泊尔、双汇、海天、海尔、伊利这六只的股价和分红画在一张图上。看完的第一反应是：这些年年分红的公司，股价怎么不太行？时寒冰举的巴菲特持仓例子，都是又涨得好、又分红不错。A股就没有这样的公司吗？

要回答这个问题，先得把“涨得好”算对。只看股价是不够的，因为分红的那部分钱，股价图上看不到。下面先把几个词说清楚，再给答案。

**几个词，一句话说清：**

- **总回报**：股价涨的钱，加上分红的钱。好比一棵果树，股价是树长高了多少，分红是每年结的果子。这篇说的总回报，都是假设每年把果子换成树苗再种下去（分红再投入），十年后一共有多少棵树。
- **年化**：十年下来，平均每年涨多少，按“利滚利”算。像存款的年利率：年化10%，十年后本金变成原来的约2.6倍。
- **股息率**：一年分红÷股价。像买一套房子出租，一年房租÷房价就是租金回报率。
- **市盈率**：股价÷每股一年的利润。像花20万买一家每年赚1万的小店，就是20倍，利润不变的话要20年回本。数字越大，买得越贵。
- **复权**：公司送股、拆股以后，一股变成两股，股价会对半跌，但你手里的钱没少。复权就是把以前的股价换算到同一把尺子上，像一个披萨切成更多块，每块变小，总量没变。
- **ROE（净资产收益率）**：股东投进去的每100元，一年给公司赚回多少。像一个100元本钱的小摊，一年赚20元，ROE就是20%。
- **幸存者偏差**：只看今天还留在场上的选手，被淘汰的不算。好比只采访中了奖的人，问买彩票划不划算。

## 二、答案：有，但570只里只有20只

我先把范围放大：今天的沪深300、中证500、中证红利三份成分股名单，再加上点名要看的几只，一共837只。<sup>[5](#ref-5)</sup> 其中570只在10年前（2016年10月底）已经上市、有完整行情。

然后定了五道门槛，要**同时**满足：

1. 10年总回报年化 ≥10%（2016-10-31 到 2026-11-09）；
2. 10年平均股息率 ≥2%；
3. 2016到2025这十个财年，每年都有现金分红；
4. 每股分红10年平均每年至少多5%，中间降超过一成的最多两次；
5. 2016–2025年的平均ROE ≥12%。

**过了五道门槛的只有20只，占570只的3.5%。** 作为对比，570只里10年总回报年化达到10%的有154只，是负数的有160只，排在正中间那只是4.4%。<sup>[1](#ref-1)</sup>

## 三、为什么会觉得“股价不行”

两个原因，一个是看法上的，一个是价格上的。

**第一，分红没算进股价。** 分红越多的公司，股价图越“吃亏”：每次分红，股价都要扣掉同样多的钱（除息），钱进了你的口袋，图上却像是跌了。长江电力10年股价年化8.3%，加上分红是12.3%；招商银行股价9.2%，加上分红是13.6%。双汇最明显：从2010年1月算起，股价年化只有1.6%，加上分红是6.2%。

![双汇发展：股价和总回报（分红再投入），以及市盈率历史](/columns/investing/tr-pe-000895.png)

<p class="chart-source">图：红线是总回报，黑线只看股价，2010-01=100，对数刻度；下栏是市盈率（近12个月）和它的中位数。数据：Tushare<sup>[1](#ref-1)</sup>、东方财富<sup>[2](#ref-2)</sup>，截至2026-11-09。</p>

两条线中间那块粉色，就是分红再投入攒出来的钱。只看黑线，会以为这家公司十几年没怎么赚钱。

**第二，2021年太贵。** 茅台的市盈率在2021年2月底到了59.8倍（那个月盘中最高73.3倍），是2010年以来月底的最高值。那个月底买入的人，算上这几年的分红，到2026年11月9日还亏20.5%，平均每年−4.0%。同一家公司，2016年10月底市盈率24.1倍时买入，10年平均每年赚18.8%。<sup>[1](#ref-1)</sup>

**判断：公司没变坏，变的是买入价。** 巴菲特在1989年的股东信里写过：用合理的价格买一家好公司，远比用好价格买一家普通公司强。<sup>[7](#ref-7)</sup> 2021年按60倍买茅台，是好公司、价格不合理。之后回报差，正好印证了这句话。

## 四、名单里五只有代表性的公司

20只里，我挑了五只分红最稳、最像巴菲特风格的画图：茅台、美的、长江电力、福耀、招商银行。它们10年里每股分红降超过一成的次数是0到1次。不按涨幅挑，是因为涨得最多的几只（生益科技、潍柴动力、鄂尔多斯）更偏周期，后面会讲。

每张图上半部分是股价（黑）和总回报（红），起点都算100；下半部分是市盈率和它自己的历史中位数（橙色虚线）。蓝线在橙线上面很多的时候买，等于付了比平时更高的价钱。

## 五、差一点没进名单的

没过门槛不等于不好，只是不符合“涨得好、分红稳还在涨”这一套标准。几个常被问到的：

- **中国神华**：10年总回报年化20.0%，平均股息率7.3%，都很高。但按财报年份，2017年每股分红3.42元（含特别分红），2018年只有0.88元；10年里降过3次。
- **陕西煤业（21.7%）、兖矿能源（18.0%）、万华化学（18.4%）**：涨得多，分红跟着煤价、化工品价格大起大落。
- **宁沪高速**：分红很稳，每股分红从2015年的0.40元慢慢加到2025年的0.49元；但10年总回报9.1%，差一点到10%。
- **格力电器**：总回报11.5%，平均股息率5.3%，但2017年度没有分红。
- **海螺水泥（5.3%）、伟星新材（4.5%）**：分红不少，但股价拖了后腿。
- **恒瑞医药（11.5%）、片仔癀（11.9%）**：涨得可以，但股息率分别只有0.3%和0.7%，主要靠股价。
- **中国移动、公牛集团、迈瑞医疗**：A股上市不满10年，没法算。

## 六、这份名单要打几个折扣

**判断：下面五条都会让结果看起来比实际好，或者让人误用。**

1. **幸存者偏差。** 名单是今天的成分股往回看。10年里被踢出指数、退市、或者表现太差没进指数的公司，都不在样本里。真在2016年闭着眼买一篮子，结果会比这里差。
2. **行业集中。** 20只里白酒3只（茅台、泸州老窖、五粮液），银行3只（招商、宁波、南京），家电2只（美的、海尔），电力2只（长江电力、川投），汽车零部件2只（潍柴、福耀）；剩下8只各占一个行业，多是覆铜板、铁合金、基建、化工、电网设备、水泥这类周期行业。周期股的分红会跟着行业起伏，不像可口可乐那样年年平稳地加。
3. **买入价决定回报。** 同一只茅台，24倍市盈率买和60倍买，是两种结果（见第三节）。
4. **生益科技排第一，但现在很贵。** 它现价÷2025年每股利润约50.8倍，涨幅主要来自最近这一段行情。过去10年的25.8%，不能直接拿来当以后的预期。
5. **巴菲特的持仓也不是只只都好。** 西方石油10年总回报0.0%。另外美股是美元计、A股是人民币计，没有换算汇率，也没扣分红的税。

## 七、这些数字怎么用

**判断：最实用的一招，是看一只好公司的市盈率现在高于还是低于它自己的历史中位数。** 它不能告诉你明天涨还是跌，但能告诉你，现在的价格比这家公司过去十几年的平常价格贵还是便宜。

按这个看法（市盈率为近12个月口径，中位数取2010年以来，美的从2013年9月起）：

| | 现在的市盈率 | 自己的历史中位数 | 相对自己 |
|---|---:|---:|---|
| 贵州茅台 | 22.0 | 28.3 | 低于中位数 |
| 美的集团 | 14.4 | 13.9 | 接近 |
| 福耀玻璃 | 17.9 | 17.3 | 接近 |
| 招商银行 | 7.1 | 7.6 | 略低 |
| 长江电力 | 22.4 | 17.5 | 明显高于 |

三条使用提醒：

- 只拿**好公司**比。生意变坏的公司，市盈率低可能是因为它真的值这么多。
- **周期股要反过来想。** 煤、化工、钢铁的利润在顶点时，市盈率反而最低；看起来便宜的时候，可能正是利润最好、要往下走的时候。
- 想要分红，就要把分红算进回报里看，不要只盯着股价图。

## 八、方法和数据说明

- **时间：** 10年是2016-10-31收盘到2026-11-09收盘，15年从2011-10-31起。A股以人民币、美股以美元计，没扣税费。
- **总回报怎么算：** 用Tushare的复权因子（收盘价×复权因子）<sup>[1](#ref-1)</sup>，等于在每次除息那天，按除权后的参考价把现金分红买回这只股票。我抽查了茅台2026-06-26那次除息：复权因子跳了1.02367倍，和“前一天收盘价÷（前一天收盘价−每股分红）”算出来一样。
- **为什么没用东方财富的“后复权”价格：** 抽查发现，它在两次除息之间价格比例会慢慢漂移，不是严格按比例复权，算出来的10年年化比实际低约1.3个百分点：茅台17.3%对18.8%，双汇4.4%对6.0%，海尔9.5%对10.8%。<sup>[2](#ref-2)</sup>
- **交叉核对：** 我又用东方财富的不复权日线加分红记录<sup>[2](#ref-2)</sup>自己算了一遍，和Tushare的结果中间值差0.0个百分点。差超过0.3个百分点的有30只，原因是东方财富的分红表漏了特别分红（比如茅台2022、2023年的两笔特别分红，中国神华2017年那笔）和配股，所以以Tushare为准。格力、云南白药等26只在2016-10-31停牌，Tushare当天没有价格，用的是自算值。
- **股价年化：** 不复权价格，只把送股、转增换算回来，不含分红。
- **股息率：** Tushare的近12个月股息率，取2016–2025每年最后一个交易日，求平均。<sup>[1](#ref-1)</sup>
- **连续分红、每股分红增长、降了几次：** Tushare分红数据，只算已经实施的，含特别分红，按送转换算到今天的股本，按财报年份加总；“降”指比上一年少一成以上。<sup>[1](#ref-1)</sup>
- **ROE：** 东方财富年报加权ROE，2016–2025平均。<sup>[2](#ref-2)</sup>
- **指数：** 中证指数官网沪深300全收益（2016-10-31为3989.45，2026-11-09为6108.28）和中证红利全收益（5599.87和12126.97）。<sup>[3](#ref-3)</sup><sup>[4](#ref-4)</sup> 官网接口查不到2011年的数，所以指数没有15年对比。
- **美股：** Yahoo Finance的复权收盘价（含分红再投入），股息率用当年分红÷年末收盘价。<sup>[6](#ref-6)</sup>
- **数据截止：** 2026-11-09收盘（北京时间15:00）。

本篇只整理公开数据，**不构成投资建议**。
