# 长期投资笔记

<p class="brief-meta">更新 2026-11-10</p>

这一栏不推荐股票，也不预测明天的涨跌。它只做一件事：用能核对的公开数据，把一类股票过去十年怎么赚钱的算清楚，再用大白话讲出来。数字的口径和来源写在每篇文末。

<!--@include: @/snippets/invest-note.md-->

和其他栏目分开：[采购人视角读财报](/columns/company-lens/) 是从买方角度读一家供应商的账本；这一栏看的是一只股票拿十年，账户里的钱怎么变。

## 已经发布

### [A股有没有“巴菲特式”股票？有，但570只里只有20只](./buffett-style-a-shares)

<p class="brief-meta">发布 2026-11-10 · 数据截至 2026-11-09 收盘</p>

又涨得好、分红又稳定增长的A股，有，但很少：有完整10年行情的570只里，同时过五道门槛的只有20只，10年总回报年化在10%到26%之间，和可口可乐、美国银行、雪佛龙在同一档；同期沪深300全收益只有4.3%。觉得“分红股股价不行”，一半是因为只看了股价、没算分红，一半是2021年估值太贵。
