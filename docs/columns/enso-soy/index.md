# 厄尔尼诺和大豆

<p class="brief-meta">更新 2026-11-26</p>

一句话：只在阿根廷站得住。阿根廷收获季碰上厄尔尼诺，单产平均比趋势高 6.6%，拉尼娜低 6.0%（自算，替身 p=0.007）。美国偏弱，巴西全国看不出来；五次大行情里三次主要落在拉尼娜，但价格和 ENSO 没有稳定的一一对应。
